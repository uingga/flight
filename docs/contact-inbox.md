# 문의함

- 기존 문의 창을 사용하며, 푸터 고객지원의 문의·의견 보내기로 진입한다. PC는 오른쪽 열, 모바일은 브랜드 소개 다음에 배치한다. 떠 있는 문의 버튼은 사용하지 않는다. 위로가기 버튼은 최하단에서도 유지하고 다른 창이 열렸을 때만 숨긴다.
- 이용 문의 / 오류 제보 / 개선 제안 / 제휴 문의를 받는다.
- PNG/JPG 한 장, 원본 1MB 이하. 클라이언트에서 최대 1600px JPEG로 다시 그려 메타데이터를 제거한다.
- 서버는 요청 크기, 이미지 시그니처, 형식, 기존 요청 제한을 검증한다. 공개 파일 주소는 만들지 않는다.
- DB는 RLS와 공개 권한 회수로 보호한다. 관리자 API는 x-admin-key 인증과 no-store를 사용한다.
- 이메일은 개인정보 없는 접수 알림만 보낸다. 알림 실패도 DB에 저장되면 접수 성공이다.
- 고객·알림 탭에서 30개씩 조회하고 본문·첨부는 상세 클릭 시에만 불러온다.
- 답변은 운영자가 이메일로 보낸다. 처리 완료 시 이름·이메일·본문·첨부를 삭제하며 복원할 수 없다.
- 미처리 문의는 운영자가 정기적으로 확인한다. 자동 답변·다중 첨부는 제공하지 않는다.
