# 공유 유입 후 항공권 탐색

2026-09-14 구현. 배포 전 미리보기 단계. 사용자 검토 후 다른 목적지 추천은 보류했다.

- 외부 공유 링크(`shared=1`과 항공권 ID)로 자동으로 처음 열린 상세에서만 같은 목적지의 다른 날짜 최대 2개와 메인 더 보기 버튼을 노출한다. 일반 메인·공유 목록에서 사용자가 직접 연 상세에는 표시하지 않는다.
- 최초 상세를 닫거나 다른 항공권을 열거나 메인 더 보기를 누르면 안내 노출 상태를 종료한다. 유입 측정용 공유 상태와 UI 노출 상태는 분리한다.
- `지금 나온 항공권 더 보기`는 상세와 필터를 해제하고 기존 메인의 최근 새 항공권 영역으로 이동한다. 새 항공권 영역이 없으면 전체 목록으로 이동한다. 운영의 DROP 선정과 새 항공권 판단 기준은 변경하지 않는다.
- `shared_browse_main`으로 이 버튼의 사용을 별도로 측정한다. 운영에서 2주간 관찰하는 실험은 아직 시작하지 않았다.
- 운영 API의 필터 통과 목록만 사용하고 기존 추천 순서를 따른다. 현재 항공권·동일 일정, 명시적 매진, 과거 및 당일 출발, 유효하지 않은 가격은 제외한다. 없는 대안을 채워 넣지 않는다.
- 인천/김포와 부산/김해는 기존 공유 필터의 권역 정의를 따른다. 카드에는 실제 출발 도시를 표기한다.
- 가격은 메인과 같은 표시 가격이며 땡처리닷컴은 발권수수료 20,000원 별도를 명시한다.
- 알림은 운영의 비활성화 설정을 유지한다. 이번 변경은 알림 기능을 다시 켜지 않는다.

## 측정

- `shared_detail_start`: 공유 진입 후 첫 항공권 상세를 연 경우.
- `shared_second_ticket_open`: 해당 페이지를 떠나거나 새로고침하기 전 서로 다른 두 번째 운항 일정을 연 경우, 한 번만 발생.
- 동일 운항의 여행사 중복·재열람은 두 번째 항공권으로 세지 않는다.
- 추천 카드 클릭은 기존 `detail_open`의 entry에 `share_discovery_same_destination` 또는 `share_discovery_same_departure`를 전달한다.
- 기존 GA 제외 브라우저 설정을 적용한다. 현재 어드민에 새 지표를 추가하지는 않았다.
- 두 이벤트는 페이지 내 탐색 지표다. 세션 단위 재방문율이나 예약·결제 전환율로 해석하지 않는다. GA 수집 차단·설정 부재에서는 수집되지 않는다.
