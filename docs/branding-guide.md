# 티키티킷 커뮤니케이션 가이드

> 모든 채널·매체의 콘텐츠 작성 시 이 문서를 최상위 기준으로 삼습니다.
> 채널별 상세 가이드는 하단 링크 참조.

---

## 1. 브랜드 개요

- **서비스**: 5개 주요 여행사의 땡처리 항공권을 한곳에 모아 보여주는 항공권 큐레이션 플랫폼
- **URL**: [tikitikit.kr](https://tikitikit.kr)
- **미션**: 고객이 '가격 낚시'에 지치지 않고, 복잡한 검색 없이 합리적인 가격으로 온전한 휴식을 떠날 수 있도록 돕는 것

### 핵심 가치 (USP)

| 가치 | 설명 |
|------|------|
| **투명성과 신뢰 (No 낚시)** | 눈속임 없는 데이터 기반 필터링 결과를 그대로 제공 |
| **자체 검증 절대 기준가** | 인터파크투어 월별 최저가를 기준으로 메리트 있는 항공권만 선별 |
| **압도적 시간 절약** | 여러 사이트를 뒤질 필요 없이 한 곳에서 진짜 저렴한 표 확인 |

## 2. 타깃 페르소나: 김티키 (v2.0)

| 항목 | 내용 |
|------|------|
| **나이/직업** | 31세, 3~5년차 직장인 |
| **상태** | 방금 퇴사했거나 번아웃으로 퇴사를 심각하게 고민 중 |
| **성격** | 차분하고 부끄러움이 있는 편. 커뮤니티에 질문 올리거나 단톡방에서 의견 묻는 걸 잘 못 한다. 다만 병맛·드라이한 유머를 좋아해서 무표정하게 던지는 한 줄에 웃긴다 |
| **행동** | 혼자 조용히 검색하고, 혼자 결정하고, 혼자 예약한다. 좋은 특가 발견 시 말없이 단톡방에 링크만 던짐 |
| **니즈** | 빡빡한 일정보다 고생한 나를 위한 '확실한 보상'과 '완벽한 휴식' (동남아 휴양지 등) |
| **페인 포인트** | 스카이스캐너 등의 낚시성 가격에 피로함, 여러 사이트 직접 비교가 귀찮음 |
| **구매 전환점** | 5개 여행사 항공권을 인터파크 기준가로 필터링해주는 투명함을 확인할 때 결제 확신 |

## 3. 브랜드 보이스: "모던 편집숍 스타일"

**레퍼런스**: 토스(Toss), 29CM — 짧고 건조하지만 확신에 찬

### 보이스 원칙

| 원칙 | 설명 |
|------|------|
| **진짜처럼** | 혼잣말하듯 쓴다. 누군가에게 보여주려고 쓰지 않는다 |
| **짧게** | 한 문장에 하나의 정보만. 문장이 길어지면 줄바꿈 |
| **건조하게** | 감탄사·느낌표 없이, 마침표로 끝낸다 |
| **솔직하게** | 못하는 건 못한다고 한다. 과장 없이 |
| **웃기되 티 안 나게** | 드라이한 셀프 디스, 무표정 유머. 웃겨달라고 하지 않는다 |

### 매체 무관 DO / DON'T

| DO ✅ | DON'T ❌ |
|-------|---------|
| 대화체, 자연스러운 경험 공유 | "~드립니다" 존댓말 광고체 |
| 팩트 기반 객관적 숫자 활용 | 감정적 호소 ("꼭 가보세요!") |
| 드라이한 셀프 디스 / 무표정 유머 | 홈쇼핑 용어 ("초특가!", "마감 임박!") |
| 브랜드명은 콘텐츠당 최대 1번 | 매 문장에 브랜드명 반복 |
| 상대 표현을 살짝 받아서 변주 | 가르치려 드는 태도, 설교/조언 |
| 공감할 땐 따뜻하되 과하지 않게 | 이모지 도배, 느낌표 남발 |

## 4. 콘텐츠 원칙 (매체 무관)

### 4-1. 후킹

읽는 사람이 **"이거 나인데?"** 하면 성공.

| 패턴 | 예시 | 심리 |
|------|------|------|
| 이분법 | "두 종류의 사람이 있다" | 자기 분류 욕구 |
| 기대 반전 | "코드를 짜고 있다. 근데 배운 적 없다" | 인지 부조화 |
| 역설적 겸손 | "아무도 안 보겠지만" | 약자 응원 심리 |
| 건조 단문 | "오늘 한 일: 버그 고침." | 무표정 주목 |
| 자조적 관찰 | "검색 실력은 늘었다" | 공감 + 웃음 |

### 4-2. 터지는 주제 vs 안 되는 주제

**🔥 10만+ 가능**
- "나만 이런가?" 계열 (공감 폭발)
- 직장인 자조 (퇴사, 월요일, 점심시간)
- 귀찮음·게으름 고백 (누구나 해당)
- A인 줄 알았는데 B (반전 = 공유)
- 혼자 만드는 사람의 외로움

**🚫 1천 이하 확정**
- 내 서비스 기능 소개 → 광고로 분류
- 기술 스택 자랑 → 관심 없음
- 업데이트 공지 → 팔로워 전용
- 정보 나열형 팁 → 블로그에 어울림
- 감사 인사·후기 → 본인 빼고 무감동

### 4-3. 문장 구조

| 항목 | 기준 |
|------|------|
| 한 문장 | **8~15자** |
| 줄바꿈 | 매 문장마다 |
| 숫자 | 콘텐츠당 1개면 충분 (구체성 ↑) |
| 감정 단어 | 1개에 집중 (분산 ❌) |
| 마지막 줄 | 반전 또는 여운 |

### 4-4. 광고 냄새 제거

| 구분 | 광고 냄새 남 | 광고 냄새 안 남 |
|------|------------|---------------|
| 첫 마디 | "안녕하세요!" | "아무도 안 보겠지만" |
| 마지막 | "방문해주세요~" | URL만 or 없음 |
| 시점 | 독자를 의식 | 혼잣말 |

## 5. 카피라이팅 규칙

### 작성 원칙

- **직관성**: 메인 카피는 15자 내외로 짧게
- **팩트 기반**: 감정적 호소보다 객관적 숫자 ('5개 여행사', '땡처리') 활용
- **비교 표현**: 가격을 일상적인 것과 비교 ("KTX 왕복보다 싼", "커피 몇 잔 값")

### 금기어

| 유형 | 금기어 예시 |
|------|-----------|
| **홈쇼핑형** | "초특가!", "마감 임박!", "단독 할인", "파격 세일" |
| **철학자형** | "궤적", "정립", "본질" 등 무겁고 사색적인 단어 |
| **과잉 감탄** | 느낌표(!) 남발, "대박", "실화냐" 반복 |
| **여행사 노출** | 여행사 개수("5개", "5대") 및 개별 이름 나열 금지 |

### 슬로건

- "항공권은 가볍게, 캐리어는 무겁게. 티키티킷"
- "비행기값 아껴서 조식 추가하세요. 티키티킷"

## 7. 채널별 가이드 (상세)

| 채널 | 톤 변형 | 상세 가이드 |
|------|--------|-----------|
| **인스타 쓰레드** | 혼잣말, 반말체 ("~했다") | → [threads-guide.md](threads-guide.md) |
| **인스타 릴스** | 화면 중심, 자막 필수 | → [reels-guide.md](reels-guide.md) |
| **네이버 블로그** | 정보 전달 + 친근한 톤, 이모지·느낌표 OK | → `/blog-edit` 워크플로우 |
| **카카오톡** | 친구에게 공유하듯, '진짜 가격표' 이미지 활용 | — |

### 채널 공통 규칙

- 브랜드명은 채널당 **하루 1회** 이내
- URL은 **꼭 필요할 때만** (쓰레드·릴스는 프로필 링크로 대체)
- "초특가/마감 임박" 등 홈쇼핑 용어는 **모든 채널에서** 금지
- 댓글 톤도 브랜드 보이스와 동일 (드라이, 짧게, 과하지 않게)

## 8. 댓글 톤 가이드

| DO ✅ | DON'T ❌ |
|-------|---------|
| 짧게, 한 줄이면 충분 | 받아치거나 빈정대는 느낌 |
| 드라이한 셀프 디스 / 무표정 유머 | 설교·조언 ("~하시면 돼요") |
| 공감할 땐 따뜻하되 과하지 않게 | 이모지 도배 |
| 상대 표현을 살짝 받아서 변주 | — |

### 댓글 예시

| 상대 댓글 | 우리 댓글 | 스타일 |
|----------|----------|--------|
| "솔직하시니 진실된 이야기도 잘 해주실 것 같아요" | "진실까진 모르겠지만 주눅은 진짜입니다. 감사해요 ㅎ" | 셀프 디스 |
| "주눅들지만 자신감 넘치게 쓰는 사람은요" | "주눅 드는데 쓰는 게 진짜 용기죠" | 따뜻한 공감 |
| "친구 하고 간다~ ㅎㅎ" | "환영합니다, 후자 모임에" | 커뮤니티 소속감 |
| "하리완료" | "감사합니다, 조용히 반갑습니다" | 톤 유지 감사 |
