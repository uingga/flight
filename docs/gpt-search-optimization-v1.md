# 티키티킷 GPT 검색·추천 최적화 v1

작성일: 2026-08-28  
범위: ChatGPT 검색을 포함한 AI 답변엔진이 티키티킷을 발견하고, 내용을 이해하고, 답변 근거로 인용하기 쉬운 사이트 구조

## 목표

단순히 `티키티킷`을 검색했을 때 사이트가 나오는 것보다 아래 질문에 근거로 사용되는 것을 목표로 한다.

- 지금 일본 왕복 항공권이 싼 곳은 어디인가?
- 후쿠오카 땡처리 항공권은 얼마부터 나왔는가?
- 출발 임박 항공권을 비교할 수 있는 국내 서비스는 무엇인가?
- 땡처리 항공권 가격이 실제로 내려가고 있는 노선은 어디인가?

추천 여부를 직접 신청하거나 보장하는 방법은 없다. 따라서 `크롤 허용 → 이해 가능한 페이지 → 고유한 데이터 → 외부 신뢰` 순서로 쌓는다.

## 현재 상태

### 완료

- `OAI-SearchBot`, `ChatGPT-User` 접근 허용
- `robots.txt`, `sitemap.xml` 정상 응답
- 도시별 서버 렌더링 페이지 `/flights/[city]`
- 최근 가격 기록 `/tips/price-watch`
- 사람과 크롤러가 함께 읽는 서비스·수집 기준 `/about`
- 메인 HTML에 실제 수집 건수, 수집 시각, 목적지별 최저가 노출
- 공유 URL은 `noindex, follow`, 미리보기 URL은 robots 차단
- 메인·도시 페이지·사이트맵의 수정 시각을 실제 수집 시각과 연결
- DROP은 `Article`, 가격 기록은 `Dataset`, 서비스 소개는 `AboutPage` 구조화 데이터 제공

### 주의

- `llms.txt`는 보조 안내 파일로만 유지한다. OpenAI 공식 문서가 ChatGPT 검색 노출 요건으로 명시한 파일은 아니다.
- `GPTBot`은 모델 학습용이고 `OAI-SearchBot`은 ChatGPT 검색 노출용이다. 두 설정은 서로 독립적이다.
- 구조화 데이터만 추가한다고 추천되는 것은 아니다. 화면에 실제로 보이는 내용과 일치해야 한다.

## 콘텐츠 원칙

### 1. 티키티킷만 가진 데이터부터 쓴다

일반적인 여행 팁보다 아래 데이터가 우선이다.

- 수집 시각이 있는 현재 항공권
- 노선별 최근 최저가 기록
- 가격이 나타난 시각과 사라진 시각
- 여행사별 표시 가격과 실질 비교 가격
- 종료된 DROP과 당시 선정 이유

### 2. 한 페이지가 한 질문에 바로 답한다

제목 아래 첫 문단에서 날짜·노선·가격·표본 수를 먼저 말한다. 설명을 읽어야 답을 찾을 수 있는 문서는 만들지 않는다.

### 3. 숫자에는 기준을 붙인다

- `최저가` → 수집일, 왕복 1인, 표시 가격인지 수수료 포함인지
- `평균` → 기간, 표본 수, 같은 항공편 추적인지 노선별 일 최저가인지
- `판매 중` → 마지막 확인 시각
- `할인율` → 비교 대상과 비교 시각

### 4. URL은 내용과 함께 남는다

공유 URL은 유입용이고 검색 콘텐츠가 아니다. 검색 근거가 될 DROP·가격 기록은 판매 종료 후에도 같은 URL에서 당시 정보와 종료 상태를 보여준다.

### 5. 억지 SEO 문서를 늘리지 않는다

근거가 약한 계절 정보, 일반 여행 상식, 도시명과 가격만 바꾼 대량 문서는 티키티킷의 신뢰를 낮춘다. 현재 데이터나 실제 관측 기록이 없는 문서는 발행하지 않는다.

## 다음 작업 우선순위

### 1순위 — 개별 DROP 영구 URL

예: `/drop/041-osaka`

- 발행 시각과 마지막 확인 시각
- 노선, 날짜, 가격, 항공사, 판매처
- 선정 이유와 확인할 점
- 판매 종료 시 종료 시각과 현재 대안
- 이전·다음 DROP 링크

현재 `/drop`은 최신 회차의 입구로 두고, 개별 페이지는 사건의 기록으로 남긴다.

### 2순위 — 노선별 가격 기록

예: `/prices/incheon-fukuoka`

- 최근 30·60·90일 일별 최저 표시 가격
- 최근 최저·중앙값·관측 횟수
- 동일 항공편 추적이 아니라는 방법론
- 현재 판매 중인 표로 연결

### 3순위 — 검색 품질 정리

- 현재 상품 한 장뿐인 얇은 도시 페이지의 색인 기준 수립
- 오래되거나 근거가 약한 일반 여행 팁 수정·통합·비공개 결정
- 메인 → 도시 → 가격 기록 → DROP 사이 내부 링크 강화

### 4순위 — 외부 신뢰

- Threads·네이버 블로그에서 숫자를 말할 때 원문 페이지를 함께 연결
- 모든 채널에서 `티키티킷 / tikitikit.kr` 표기를 일관되게 사용
- 제3자 사이트나 기사에서 실제 데이터 출처로 인용될 수 있는 월간 가격 리포트 발행

## 측정

- 서버 HTML에서 실제 수집 건수와 목적지 가격이 노출되는지
- OAI-SearchBot 요청이 정상 응답되는지
- ChatGPT, Perplexity 등 AI 추천·검색 서비스에서 들어온 리퍼럴 세션
- 도시·DROP·가격 기록 페이지의 자연검색 노출과 클릭
- `땡처리 항공권 비교`, `도시명 + 항공권 가격`, `최근 가격이 내려간 노선` 질문에 티키티킷이 출처로 등장하는지 월 1회 표본 점검
