# 티키티킷 DROP·데이터·브랜드·마케팅 대화 원문 모음

> 사용자가 붙여넣은 두 문서에서 비교 대상 서비스 자체에 대한 설명·분석·비교 문장만 제외하고, 티키티킷에 관한 나머지 원문을 표현과 순서를 바꾸지 않은 채 합쳤습니다.

## 원문 2 — DROP 브랜드와 퍼지는 제품 아이디어

예를 들면 우리가 전에 얘기한 오늘의 DROP #037 같은 게 그 출발점이야.

현재 9석

그리고 더 재미있는 방향은 **‘가격을 싸게 찾는 서비스’가 아니라 ‘이상한 가격을 발견하는 사람들의 클럽’**으로 가는 거라고 봐.
오늘의 DROP
→ “뭐 떨어졌나?” 보러 옴
→ 좋은 드롭에 번호가 붙음
→ 지나간 드롭도 기록으로 남음
→ “작년 오사카 4.9만 원 전설의 DROP #128” 같은 이야기가 생김
→ 사람들끼리 제보함
→ 좋은 가격을 잡은 사람이 인증함
내가 지금 둘을 비교하면 이렇게 보여.
