# 최근 본 표

2026-09-07: 비회원도 사용할 수 있는 브라우저별 최근 열람 기록을 추가한다.

- 목록 제목 줄의 추천순 왼쪽에 표시한다. 기록이 없으면 숨긴다.
- 제목·항공권 개수·갱신 시각은 모두 유지한다. 공간이 부족할 때만 왼쪽 정보가 자연스럽게 두 줄로 내려간다.
- 실제 상세를 연 항공권만 최근 10개/30일 보관한다. localStorage의 `tikitikit_recent_flights_v1`을 사용하고 다른 탭의 기록 변경도 반영한다.
- 로그인 계정의 기존 기록과 별개다. 기기 간 동기화는 제공하지 않는다.
- 저장 데이터에는 표시/동일 상품 확인용 정보만 포함하며 예약 링크는 보관하지 않는다. 실제 현재 목록에서 동일 항공권을 다시 찾았을 때만 상세를 연다.
- 삭제/품절 여부를 추측하지 않는다. 목록 조회가 완료되기 전에는 확인 중, 이후에도 없으면 마지막으로 본 정보임을 표시한다. 저장된 예전 항공권의 예약 링크를 재사용하지 않는다.
- 저장 불가 시 현재 화면 메모리에서만 유지하며 안내한다.
- 공지, 인원 선택, 크롤링·운영 데이터 정책은 변경하지 않는다.

‘지난 방문 이후’는 향후 인사이트바 아이디어로 보류한다. 가상 방문 데이터 및 검은 테스트 메뉴는 운영에 추가하지 않는다.

검증: `npm run build`, `npx tsx scripts/test-recent-flights.ts`, `npx tsx scripts/verify-recent-flights.ts [URL]`, `npm run test:redesign -- [로컬 미리보기 URL]`.
기존 리디자인 검증은 PC 상세가 비모달 오른쪽 패널인 현행 동작에 맞춰 배경 잠금 기대값을 모바일에만 적용한다.
