# 티키티킷 UI 디자인 시스템

운영 메인 리디자인(`src/app/preview/mobile-redesign`)의 시각 규격이다. 화면을 새로 꾸미기 위한 문서가 아니라, 이미 확정한 디자인이 컴포넌트마다 달라지지 않게 유지하는 기준이다.

## 적용 범위

- 메인 항공권 목록과 카드
- 필터와 정렬 메뉴
- 항공권 상세
- 특가 알림
- 내 여행·로그인
- 문의와 안내 팝업

토큰의 코드상 기준점은 `page.module.css`의 `.previewPage`다. 별도 CSS Module도 가능한 한 이 토큰을 상속하고, 토큰이 없는 독립 렌더링을 대비해 동일한 폴백값을 둔다.

## 서체

- 영문·숫자: Inter
- 한글: 운영체제 시스템 한글 폰트
- 허용 굵기: `400`, `600`, `700`, `800`
- `500`, `650`, `750`, `850`처럼 실제로 불러오지 않는 굵기는 사용하지 않는다.

| 역할 | 모바일 | PC | 굵기 |
| --- | ---: | ---: | ---: |
| 아주 작은 보조 정보 | 10px | 10px | 400 또는 600 |
| 캡션 | 11px | 12px | 400 또는 600 |
| 메타·컨트롤 | 12px | 13px | 600 |
| 본문 | 14px | 15px | 400 |
| 섹션 제목 | 16px | 18px | 700 |
| 카드 핵심 정보 | 18px | 20px | 700 |
| 패널 제목 | 20px | 23px | 700 |
| 상세 가격 | 22px | 25px | 800 |
| 큰 표시 제목 | 24px | 28px | 700 |

### 굵기 사용 원칙

- `400`: 설명, 날짜·시간, 기본값, 보조 정보
- `600`: 버튼, 필터 항목명, 탭, 여행사·항공사 등 조작·식별 요소
- `700`: 페이지·패널·섹션 제목과 주요 버튼
- `800`: 가격, TIKIT DROP, 상단 경보처럼 의도적으로 강한 정보

일반 팝업 제목과 주요 버튼에 `800`을 사용하지 않는다.

## 색상

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--brand` | `#ff385c` | 선택 상태, 핵심 강조 |
| `--brand-dark` | `#e00b41` | 강조 텍스트, 주요 CTA |
| `--brand-soft` | `#fff0f3` | 연한 선택 배경 |
| `--ink` | `#222222` | 제목과 본문 핵심 정보 |
| `--text-secondary` | `#5f5f5f` | 보조 본문 |
| `--text-muted` | `#707070` | 메타 정보 |
| `--text-faint` | `#737373` | 작은 안내 문구의 접근 가능한 최저 명도 |
| `--paper` | `#ffffff` | 카드와 패널 |
| `--paper-soft` | `#f7f7f7` | 보조 영역 |
| `--line` | `#dddddd` | 기본 구분선 |
| `--canvas` | `#f3f3f3` | 페이지 바깥 배경 |

핑크는 브랜드를 알리거나 사용자가 선택한 상태를 보여줄 때 사용한다. 단순한 제목, 일반 정보, 모든 아이콘에 반복해서 사용하지 않는다.

## 컴포넌트 원칙

- 같은 역할의 패널 제목은 모바일 `20px/700`, PC `23px/700`으로 통일한다.
- 기본 필터값 `전체`는 항목명보다 약하게, 선택된 값만 브랜드색으로 표시한다.
- 주요 버튼은 `700`; 가격과 DROP이 아닌 일반 버튼을 `800`로 만들지 않는다.
- 작은 글씨는 명도만 낮추지 않고 최소 크기와 대비를 함께 확인한다.
- 모바일과 PC는 정보 구조를 공유하되, 크기 토큰만 미디어 쿼리에서 조정한다.

## 변경할 때 확인할 것

1. 새 숫자 크기나 굵기를 직접 넣기 전에 기존 토큰으로 표현 가능한지 확인한다.
2. 메인·상세·특가 알림·내 여행에서 같은 역할이 같은 규격인지 확인한다.
3. `npm run build`를 통과한 뒤 모바일과 PC에서 제목, 버튼, 가격의 위계가 서로 경쟁하지 않는지 확인한다.
