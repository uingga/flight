# 티키티킷 UI 디자인 시스템

운영 메인 리디자인(`src/app/preview/mobile-redesign`)의 시각 규격이다. 화면을 새로 꾸미기 위한 문서가 아니라, 이미 확정한 디자인이 컴포넌트마다 달라지지 않게 유지하는 기준이다.

## 적용 범위

- 메인 항공권 목록과 카드
- 필터와 정렬 메뉴
- 항공권 상세
- 특가 알림
- 내 여행·로그인
- 문의와 안내 팝업

토큰의 코드상 기준점은 `page.module.css`의 `.previewPage`다. 별도 CSS Module도 가능한 한 이 토큰을 상속하고, 토큰이 없는 독립 렌더링을 대비해 동일한 폴백값을 둔다. `globals.css`의 레거시 달력 규칙은 `.legacy-dashboard` 아래에서만 적용하며, 운영 리디자인 달력은 `page.module.css`의 `.dateCalendar` 규칙과 `.previewPage` 토큰만 사용한다.

## 서체

- 영문·숫자: Inter
- 한글: 운영체제 시스템 한글 폰트
- 허용 굵기: `400`, `600`, `700`, `800`
- `500`, `650`, `750`, `850`처럼 실제로 불러오지 않는 굵기는 사용하지 않는다.

| 역할 | 모바일 | PC | 굵기 |
| --- | ---: | ---: | ---: |
| 아주 작은 보조 정보 | 10px | 10px | 400 또는 600 |
| 캡션 | 11px | 12px | 400 또는 600 |
| 메타·컨트롤 | 12px | 13px | 600 |
| 본문 | 14px | 15px | 400 |
| 섹션 제목 | 16px | 18px | 700 |
| 카드 핵심 정보 | 18px | 20px | 700 |
| 패널 제목 | 20px | 23px | 700 |
| 상세 가격 | 22px | 25px | 800 |
| 큰 표시 제목 | 24px | 28px | 700 |

### 굵기 사용 원칙

- `400`: 설명, 날짜·시간, 기본값, 보조 정보
- `600`: 버튼, 필터 항목명, 탭, 여행사·항공사 등 조작·식별 요소
- `700`: 페이지·패널·섹션 제목과 주요 버튼
- `800`: 가격, TIKIT DROP, 상단 경보처럼 의도적으로 강한 정보

일반 팝업 제목과 주요 버튼에 `800`을 사용하지 않는다.

## 모서리와 오버레이

| 토큰 | 값 | 용도 |
| --- | ---: | --- |
| `--radius-card` | 모바일 `10px` / PC `12px` | 항공권 카드 |
| `--radius-control` | `10px` | 칩·입력·작은 컨트롤 |
| `--radius-action` | `13px` | 주요 버튼 |
| `--radius-sheet` | `12px` | 기본 모바일 바텀시트 |
| `--radius-sheet-prominent` | `16px` | 특가 알림 바텀시트 |
| `--radius-dialog` | `22px` | PC 중앙 창·모바일 계정 시트 |
| `--radius-frame` | `24px` | PC 미리보기 프레임·계정 중앙 창 |
| `--radius-pill` | `999px` | 원형·알약형 요소 |
| `--overlay-scrim-mobile` | `rgba(24, 27, 32, 0.4)` | 모바일 배경 음영 |
| `--overlay-scrim-desktop` | `rgba(24, 27, 32, 0.2)` | PC 배경 음영 |
| `--overlay-backdrop-filter` | `blur(2px)` | 모달 뒤 콘텐츠 흐림 |

오버레이의 공통 렌더링 기준은 `src/components/ui/OverlayDialog.tsx`다. 이 컴포넌트와 `use-overlay-dialog.ts`가 배경 클릭, 최상단 ESC 닫기, 중첩 가능한 스크롤 잠금, 포커스 진입·트랩·복원을 담당한다. `overlay-history.ts`는 필터·내 여행·문의에도 상세·특가 알림이 쓰던 `tikitikitOverlay` 이력 규약을 적용해, 브라우저 뒤로가기에서 최상단 레이어부터 닫히게 한다.

레이아웃은 공통화 대상이 아니다. PC 상세는 오른쪽 패널, 필터는 트리거 기준 팝오버, 문의·내 여행·특가 알림은 중앙 창을 유지하고 모바일에서는 바텀시트를 사용한다. PC 필터처럼 배경 음영이 없는 레이어는 로컬 CSS에서 오버레이 토큰만 투명하게 재정의한다.

## 컴포넌트 원칙

- 같은 역할의 패널 제목은 모바일 `20px/700`, PC `23px/700`으로 통일한다.
- 기본 필터값 `전체`는 항목명보다 약하게, 선택된 값만 브랜드색으로 표시한다.
- 주요 버튼은 `700`; 가격과 DROP이 아닌 일반 버튼을 `800`로 만들지 않는다.
- 작은 글씨는 명도만 낮추지 않고 최소 크기와 대비를 함께 확인한다.
- 모바일과 PC는 정보 구조를 공유하되, 크기 토큰만 미디어 쿼리에서 조정한다.
- 포인터 클릭에서는 포커스 외곽선을 표시하지 않고, `Tab`으로 시작한 키보드 탐색에서만 `:focus-visible` 외곽선을 표시한다.

## 변경할 때 확인할 것

1. 새 숫자 크기나 굵기를 직접 넣기 전에 기존 토큰으로 표현 가능한지 확인한다.
2. 메인·상세·특가 알림·내 여행에서 같은 역할이 같은 규격인지 확인한다.
3. 모달을 추가할 때 개별 `body.style.overflow`, ESC 리스너, 포커스 트랩을 만들지 않고 `OverlayDialog`를 사용한다.
4. `npm run build`와 `npm run test:redesign`을 통과한 뒤 모바일과 PC에서 제목, 버튼, 가격의 위계와 오버레이 닫기 순서를 확인한다.
