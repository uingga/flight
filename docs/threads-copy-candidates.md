# Threads 문구 후보

티키티킷 Threads의 캐릭터와 문장 리듬을 맞추기 위한 참고 문서다.

아래 문장들은 순서대로 돌려 쓰는 고정 문구나 도시·가격만 바꾸는 템플릿이 아니다. 실제 항공권에서 그날 가장 이상하거나 재미있는 사실을 찾고, 매번 새로운 문장을 만든다. 기존 예시는 새 문장이 티키티킷답게 들리는지 비교하는 기준으로만 사용한다.

## 계정의 목적

티키티킷 Threads의 목적은 항공권을 많이 올리는 게 아니라 “항공권 가격을 매일 들여다보는 이상한 사람”이라는 캐릭터를 만드는 것이다.

아래 가격·일정·편수는 문구 예시다. 실제 게시 전 당일 항공권 데이터와 예약 가능 여부를 확인하고 숫자를 교체한다. 첫 예시처럼 한 문구 안의 가격이 다르면 반드시 하나로 맞춘다.

## 문체 원칙

1. 흥분은 하되 호들갑은 짧게.
2. 설명은 숫자로.
3. 회사 말투 말고 사람이 말하는 것처럼.
4. 링크보다 먼저 친구한테 보내고 싶은 한 문장을 만든다.

## 기존에 잡아둔 문장 예시

### 1. 친구한테 먼저 보내는 가격

```text
후쿠오카 왕복 58,900원 떴습니다.
이 가격이면 여행 계획을 세우는 게 아니라
친구한테 먼저 보내는 게 맞습니다.
```

### 2. 이유까지 알 필요 없는 가격

```text
항공권이 싸지는 데는 이유가 있습니다.
하지만 59,800원이면
이유까지 알 필요는 없습니다.
```

### 3. 결제 기준 질문

```text
일본 왕복 항공권이 얼마면
목적지도 안 보고 결제할 수 있나요?
나는 7만원.
```

### 4. 빨리 보내는 사람이 잡는다

```text
특가 항공권을 잡는 사람은
여행 계획을 잘 세우는 사람이 아니라
친구에게 빨리 보내는 사람입니다.
```

### 5. 연차는 없지만 여권은 있는 사람

```text
연차는 없지만
여권은 있는 사람을 위한 항공권.
금요일 밤 출발
일요일 밤 귀국
오사카 왕복 72,100원
```

### 6. 계정 선언

```text
여행 꿀팁 계정을 만들 생각은 없습니다.
이상하게 싼 항공권이 뜨면
그것만 올리겠습니다.
```

### 7. 오늘은 없음

```text
오늘 항공권 1,842개 봤는데
올릴 만한 거 없음.
다들 그냥 집에 계세요.
```

### 8. 싼 대신 이른 출발

```text
오사카 14.8만
싸긴 한데
오전 6시 40분 출발이라
사실상 전날부터 여행 시작임.
```

### 9. 가격 추적 연속 게시

첫 게시:

```text
오늘 아침부터
오사카 항공권만 37번 새로고침 중.
16.2 → 15.8 → 15.4
조금만 더 내려와봐.
```

몇 시간 후:

```text
14.9 됨.
잡았다.
```

### 10. 이번 주 미친놈상

```text
이번 주 미친놈상
인천 → 오사카
왕복 118,700원
버스 타고 부산 가도 비슷합니다.
```

### 11. 헤어졌다면

```text
헤어졌다면 후쿠오카 12.4
안 헤어졌어도 12.4
```

### 12. 팀장님께는 알아서

```text
금요일 연차 하나 쓰면
오사카 왕복 13.8.
팀장님께는 알아서 하세요.
```

### 13. 자기계발보다 타이베이

```text
여러분에게 지금 필요한 건
자기계발이 아니라
14만원짜리 타이베이일 수도 있습니다.
```

### 14. 후쿠오카한테 연락

```text
후쿠오카한테 연락이 왔네요. “주말에 뭐 함?”
후쿠오카 왕복 64,100원
```

### 15. 침착한 편

```text
도쿄 왕복 69,700원
이거 보고도 일정부터 확인하면 침착한 편.
```

### 16. 오사카가 적극적

```text
오사카가 갑자기 좀 적극적이네요.
왕복 58,900원
```

### 17. 여행 계획이 생김

```text
여행 계획 없었는데 생겼습니다.
후쿠오카 왕복 61,200원
```

### 18. 목적지가 정한 여행

```text
이 정도면 목적지는 후쿠오카가 정한 겁니다.
왕복 63,900원
```

### 19. 오늘의 미친놈

```text
오늘의 미친놈.
후쿠오카 왕복 61,200원
```

### 20. 백수 우대 항공권

```text
아니 도쿄 왕복이 11만원인데
출발이 다음 주 월요일이다.
백수 우대 항공권인가.
```

### 21. 오사카 가격 상승

```text
요즘 오사카 왜 이렇게 비싸지?
지난주보다 확실히 올라갔다.
```

### 22. 제주도와 후쿠오카

```text
9만원 제주도 vs 13만원 후쿠오카
이쯤 되면 제주도 가려다가 여권 찾게 됨.
```

### 23. 오사카 이민

```text
오늘의 이상한 표 #004
인천 → 오사카
119,000원
그런데 8박 9일.
오사카에 이민 갈 사람 구함.
```

### 24. 전원 정지

```text
전원 정지.
후쿠오카 49,800원입니다.
```

### 25. 삼가 고가의 명복을 빕니다

```text
오사카 왕복
₩49,800
짧지만 아름다운 가격이었습니다.
향년 46분
삼가 고가의 명복을 빕니다
```

## 새 문구를 만들 때 확인할 것

1. 첫 문장이 링크 없이도 친구에게 전달할 만한가.
2. 가격, 출발지, 목적지, 왕복 여부가 실제 데이터와 일치하는가.
3. 일정이나 출발 시각을 말한다면 실제 편과 일치하는가.
4. 같은 노선과 비슷한 가격을 최근에 반복해서 올리지 않았는가.
5. 가격이 평범하면 억지로 올리지 않는다.
6. 기존 예시에서 도시와 가격만 바꾼 문장이 아닌가.
7. 그 항공권에서만 나올 수 있는 숫자·일정·가격 변화가 들어갔는가.
8. 기존 예시보다 더 좋은 새 문장이 나오면 반복 사용 목록으로 만들지 말고 새로운 참고 사례로 축적한다.
