# 티키티킷 릴스 콘텐츠 가이드

## 톤앤매너
- 쓰레드 가이드와 동일 (혼잣말, 반말, 광고 냄새 zero)
- 첫 1초가 전부 — 스크롤 멈추게 만드는 장면으로 시작
- 얼굴 노출 최소화 (화면 녹화, 탑뷰, 뒷모습 중심)
- 자막 필수 — 음소거 시청 비율 80% 이상

## 제작 원칙
- 영상 길이: 15~30초 (짧을수록 좋음)
- 자막: 한 줄에 10자 이내, 화면 중앙 하단
- BGM: 잔잔하거나 없음 (효과음으로 대체)
- CTA: 영상 내 브랜드 노출 최대 1회, 자연스럽게

# 릴스 초안 백로그

## #1 — 검색 기록
- **유형**: 화면 녹화형
- **앵글**: 폰 검색 기록 스크롤 — 전부 "항공권 특가", "땡처리", "세부 비행기"
- **자막**: `6개월째 검색만 하고 있다`
- **효과음**: 조용한 피아노 한 음 (쓸쓸함)
- **다음 장면**: "검색 실력은 늘었다" 자막 + 무음
- **연결 쓰레드**: 검색 6개월

## #2 — 새벽 2시 화면
- **유형**: 화면 녹화형
- **앵글**: 폰 상단바 시간 "02:17" + 항공권 검색 화면
- **자막**: `새벽 2시에 할 짓이 이거냐`
- **효과음**: 없음 (무음이 오히려 몰입)
- **다음 장면**: "네" 자막만 1초

## #3 — 노트북 앞 멍때림
- **유형**: 실사 촬영형
- **앵글**: 어깨 뒤에서 노트북 화면 보이게 (코드 에디터 열려있음)
- **표정**: 안 보임 (뒷통수만)
- **자막**: `코딩 배운 적 없는 사람이 사이트를 만들면`
- **효과음**: 키보드 타이핑 소리 → 멈춤 → 한숨
- **연결 쓰레드**: 코딩 못하는 사람
