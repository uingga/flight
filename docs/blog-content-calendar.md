## 작성 규칙

1. 새 포스트 완성 시 → "발행 완료" 섹션으로 이동
2. 파일명: `public/blog-post-{번호}.html`
3. 스타일: 기존 01, 02번 포스트 형식 참고
4. 하단 CTA → tikitikit.kr 링크 필수
