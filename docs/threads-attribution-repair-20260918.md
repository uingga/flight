## 향후 글을 게시할 때

1. `/t/<code>` 또는 `/t/g-<group>` 추적 링크를 사용한다. 일반 `/share-group/` 주소만 복사하면 글별 추적이 되지 않는다.
2. 실제 게시 후 원글·본인 댓글·그 안의 링크를 확인하고 다음 명령으로 관계를 등록한다. 코드를 재사용하면 통계가 합쳐지므로 글을 나누어 측정하려면 글마다 고유한 `utm_content`를 사용한다.

```powershell
npx tsx scripts/register-threads-link.ts --post-url ROOT_URL --reply-url OWN_REPLY_URL --link TRACKED_URL --verified-on YYYY-MM-DD --confirm-verified
```

등록 명령은 로컬 JSON만 수정한다. 게시·배포·통계 수집을 실행하지 않는다. 등록부 변경은 정상 코드 배포 후 운영에 반영된다. 공개 글 수정과 배포는 각각 사용자 승인 범위에 따른다.
