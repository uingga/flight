# 모두투어 재등장 이력 보존

네이버 가격 필터로 숨겨진 항공권이 다음 수집에서 같은 가격으로 돌아와도 신규 항공권으로 취급하지 않는다. 상품번호·공항·왕복일·항공사·편명이 같은 항공권의 최초 발견일, 마지막 관측 가격, 과거 최저가, 유효한 가격 하락 사건을 `all-flights-cache.json.modetourOfferHistory`에 별도로 보존한다. 지난 출발일의 이력만 정리한다.

일반 수집, 수동 모두투어 반영, 네이버 필터, 소스별 병합이 이력을 이어받는다. 가격 인상 뒤 이전 가격 복귀는 새로운 가격 하락 사건으로 만들지 않으며, 실제 신규 최저가는 기존 1만원/5% 기준을 유지한다. 판매·좌석·노출 판단이나 네이버 제외 기준을 바꾸지 않는다.

`src/lib/modetour-history-bootstrap.json`은 2026-09-10~18 운영 Git 관측본으로 확인한 235개 미래 일정의 일회성 복원본이다. 과거에 누락된 시각이나 가격은 추정하지 않는다. API와 정적 페이지가 같은 복원 규칙을 사용해 배포 직후 기존 캐시의 잘못 갱신된 신규 날짜도 교정한다. 이후 관측은 캐시 이력으로 이어진다. 출발일이 모두 지난 뒤 이 복원본은 별도 정리할 수 있다.

검증: `scripts/test-modetour-offer-history.ts`, 기존 `scripts/test-recommendation-news.ts`, `scripts/test-modetour-manual.ts`. `scripts/verify-modetour-history.ts`는 캐시를 변경하지 않고 현재 표의 날짜 복원을 검증한다. 복원본 생성 스크립트는 오프라인 Git 이력 전용이며 정규 수집에서 실행하지 않는다.
