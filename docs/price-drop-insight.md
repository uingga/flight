# 가격 하락 인사이트바

- 제목: 기다린 보람이 있네요
- 설명: 최근 가격이 내려간 항공권을 모았어요.
- 첫 인사이트바는 일반 카드 9개 뒤, 가격 하락은 21개 뒤. 하락 후보가 없으면 기존 인사이트 순서를 유지한다.
- 원본은 비공개 Supabase `flight_price_daily`. 서버의 읽기 전용 API `/api/price-drop-flights`에서만 조회한다. 수집 횟수나 기록 쓰기는 추가하지 않는다.
- 기존 생애 기록의 `offerKey`와 여행사, 실제 출도착 공항, 출발·귀국 날짜, 양쪽 출발 시간, 항공사를 모두 대조한다. 시간이나 항공사가 없으면 제외한다.
- 한국 날짜 기준 어제~3일 전의 일별 관측치만 비교한다. 보존된 캐시를 새 기록처럼 쓰지 않도록 `price_checked_at`의 한국 날짜가 해당 관측일과 같아야 한다.
- 현재 표시 가격(`listed_price`와 동일한 기준)보다 높은 과거 기록 중 가장 가까운 날짜를 선택한다. 노선 평균가나 다른 여행사 가격은 쓰지 않는다.
- 선택한 비교 기록보다 10,000원 이상 내려간 일정만 노출한다. 10,000원 미만이면 더 오래된 큰 하락 기록으로 바꿔 보여주지 않는다. 이 기준은 API에서 적용해 표시 개수와 목록에도 동일하게 반영한다.
- 실제 비교 날짜에 따라 `어제보다`, `2일 전보다`, `3일 전보다`를 표시한다. 금액을 올림하지 않는다.
- 화면에서는 현재 목록에 있는 일정만 사용하고 API 계산 당시 현재 가격이 화면 가격과 일치할 때만 보여준다. 총 개수는 중복을 제외한 표시 일정 수다.
- 기록 조회 실패·설정 부재·비교 후보 없음은 바를 숨긴다. 예시 항공권이나 임의 할인 금액으로 대체하지 않는다.
- 기록 쿼리는 5분 캐시, API는 1분 캐시. 한국 날짜가 바뀌면 이전 날짜 응답을 화면에서 무시한다.
- 클릭하면 해당 일정의 기존 상세창을 연다. 자동 슬라이드와 드래그는 기존 인사이트바 동작을 재사용한다.

검증: `npx tsx scripts/test-price-drop-insight.ts`, `node scripts/test-price-drop-browser.cjs` (`PRICE_DROP_TEST_URL`로 테스트 서버 지정).
