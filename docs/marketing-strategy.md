# 티키티킷 마케팅 전략

> 작성: 2026-08-14. 브랜드 톤·페르소나는 [branding-guide.md](branding-guide.md)를 최상위 기준으로 따른다.
> 이 문서는 "무엇을, 어떤 순서로, 얼마나" 실행할지의 전략 문서.

---

## 1. 현재 자산 진단

| 자산 | 상태 | 평가 |
|------|------|------|
| 네이버 블로그 (일일 특가 포스트) | 자동화 완료 (`draft-naver-blog.mjs`) | ✅ 유지비 0에 가까운 핵심 엔진 |
| 네이버 블로그 (정보성 포스트) | 9편 발행, 캘린더 백로그 있음 | ✅ 검색 유입 복리 자산 |
| 쓰레드 | 가이드 + 초안 백로그 있음 | ⚠️ 발행 캐던스 불명확 — 실행이 병목 |
| 릴스 | 가이드 + 초안 백로그 있음 | ⚠️ 제작 비용 높음, 미착수 추정 |
| 트위터 봇 | 로그인 차단으로 실험 중단 상태 | ❌ 보류 권장 (한국 타깃 대비 효율 낮음) |
| 가격 알림 (이메일/푸시) | 기능 구현 완료 | 🔑 리텐션 핵심 — 마케팅 전환 목표로 승격 |
| 공유 기능 (`/share/[id]`, OG 이미지) | 구현 완료 | 🔑 페르소나("단톡방에 링크만 던짐")와 정합 |
| GA4 이벤트 추적 | 카드/예약/필터/공유 클릭 추적 중 | ✅ 측정 기반 있음 |

**요약**: 콘텐츠 가이드와 제품 기능은 준비돼 있고, 부족한 것은 **일관된 발행 캐던스**와 **유입→알림 구독 전환 설계**다.

## 2. 목표와 퍼널

솔로 운영이므로 목표는 3개만 잡는다 (분기 단위 갱신).

```
인지 (블로그·쓰레드·커뮤니티)
  → 방문 (tikitikit.kr)
  → 활성 (카드 클릭, 예약 클릭)
  → 리텐션 (가격 알림 구독, 재방문)
  → 확산 (공유 링크 → 단톡방/커뮤니티)
```

### 북극성 지표

**주간 예약 클릭 수** (`booking_click`) — 매출 대리 지표이자 모든 채널의 최종 성과.

### 보조 KPI (주간 체크)

| 지표 | 소스 | 이유 |
|------|------|------|
| 신규 방문자 | GA4 | 인지 채널 효과 |
| 가격 알림 구독 수 | alerts.json / GA4 | 리텐션 자산 축적 |
| 공유 클릭 수 | GA4 `share` 이벤트 | 확산 루프 작동 여부 |
| 네이버 검색 유입 키워드 | 네이버 서치어드바이저 | SEO 방향 보정 |

## 3. 채널 전략: 우선순위와 역할

원칙: **자동화 가능한 것 → 복리가 쌓이는 것 → 일회성 노출** 순으로 투자한다.

### Tier 1 — 검색 (네이버 + 구글): 복리 엔진

- **일일 특가 포스트**: 현행 유지. 제목 키워드 패턴(`[M/D] 땡처리 항공권 특가 TOP 3 | …`) 준수.
- **정보성 포스트 주 1편**: [blog-content-calendar.md](blog-content-calendar.md) 우선순위(⭐⭐⭐) 순서대로. 특히 시즌물 선점 — 8월 현재라면 "추석 연휴 항공권"(연휴 2개월 전 규칙)이 최우선.
- **사이트 자체 SEO**: `/tips` 페이지가 구글용 자산. 블로그 포스트를 `/tips`에도 미러링해 도메인 권위를 사이트에 쌓는다 (네이버 블로그는 네이버 안에서만 복리).
- **네이버 서치어드바이저 / 구글 서치콘솔 등록 확인** — 미등록이면 즉시.

### Tier 2 — 쓰레드: 브랜드와 바이럴

- 캐던스: **주 3회** (매일은 번아웃 리스크, 주 1회는 알고리즘에 죽음).
- 소재는 가이드의 "터지는 주제" 우선 — 서비스 소개가 아니라 **만드는 사람의 이야기** ("코딩 배운 적 없는 사람이 사이트를 만들면"). 백로그 초안부터 소진.
- 특가 정보는 10편 중 1~2편만, 브랜드명 최대 1회 규칙 유지.

### Tier 3 — 커뮤니티 시딩: 초기 점화 (신규)

가이드에 없는 영역이지만 초기 트래픽에는 가장 효과적.

- **어디에**: 뽐뿌 항공정보, 네이버 여행 카페, 클리앙 알뜰구매 등 특가 공유 문화가 있는 곳.
- **어떻게**: 서비스 홍보 글 ❌ → **진짜 좋은 특가를 발견했을 때만** 해당 딜 + 공유 링크를 올린다. 페르소나 행동("좋은 특가 발견 시 말없이 링크만 던짐")과 동일한 방식.
- **빈도**: 주 1~2회, 정말 좋은 딜이 있을 때만. 커뮤니티별 홍보 규정 사전 확인 필수 — 강퇴당하면 채널 하나가 영구 소멸.

### Tier 4 — 카카오 오픈채팅: 리텐션 채널 (신규, 검토)

- "땡처리 항공권 알림방" 개설 → 일일 Top 3를 이미지 카드로 공유.
- 블로그 자동화 산출물 재활용이라 추가 제작비 거의 0. 구독형 채널이라 알림 기능과 함께 리텐션 양대 축.

### 보류

- **릴스**: 제작비 대비 검증 안 됨. 쓰레드에서 터진 소재만 릴스로 2차 가공 (월 1~2편 상한).
- **트위터 봇**: 중단 유지. 한국 여행 타깃 도달 대비 유지비 과다.
- **유료 광고**: 오가닉 퍼널이 검증되기 전에는 집행하지 않는다 (3개월 후 재검토).

## 4. 제품 주도 성장 (사이트 안에서 할 일)

마케팅으로 데려온 방문자를 자산으로 바꾸는 장치. 유입보다 이쪽 개선이 ROI가 높을 수 있다.

1. **알림 구독 CTA 강화**: 첫 방문자가 알림 기능을 인지하는지 점검. 관심 노선 필터링 직후가 최적 타이밍 ("이 노선 더 싸지면 알려드릴까요").
2. **공유 카드 품질**: 단톡방에 던져진 링크의 OG 미리보기가 가격·노선을 한눈에 보여주는지 확인 — 이게 사실상 광고 소재다.
3. **재방문 이유 만들기**: 가격 히스토리(`price-history.json`) 기반 "어제보다 내린 노선" 같은 데일리 변화 요소.

## 5. 주간 운영 루틴 (솔로 기준, 주 4~5시간)

| 요일 | 작업 | 시간 |
|------|------|------|
| 매일 | 일일 특가 포스트 발행 (자동 초안 → 검수 · 업로드) | 10분 |
| 월 | 정보성 블로그 1편 작성·발행 | 1.5h |
| 화·목·토 | 쓰레드 1편 (백로그에서) + 댓글 대응 | 각 15분 |
| 금 | 좋은 딜 있으면 커뮤니티 1건 공유 | 15분 |
| 일 | KPI 리뷰 (GA4 + 서치어드바이저) → 다음 주 소재 결정 | 30분 |
