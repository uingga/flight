## 1. 전략의 결론

티키티킷은 `여러 여행사의 항공권을 한곳에서 보세요`라는 말로 알려지지 않는다.

> **항공권을 검색하는 사이트가 아니라, 말도 안 되는 가격이 발생하는 곳.**

사람들이 티키티킷을 여는 이유를 바꾼다.

```text
항공권이 필요하다 → 검색한다
               ↓
오늘 뭐 떴지? → 발견한다 → 친구에게 보낸다 → 잡거나 놓친다
```

DROP 하나가 상품이면서 콘텐츠이고, 공유 카드이며, 알림이고, 나중에는 기록과 이야기까지 된다.

서비스명은 `tikitikit(티키티킷)`으로 유지하고, 공개되는 대표 콘텐츠와 사건의 이름은 `TIKIT DROP(티킷 드롭)`으로 사용한다.

마케팅의 목표는 방문자를 잠깐 늘리는 것이 아니다.

1. 사람들이 `오늘 뭐 떴지?` 하고 다시 들어온다.
2. 이상한 가격을 보면 `야, 이거 봐봐` 하고 보낸다.
3. 좋은 표를 잡은 사람은 자신의 득템을 자랑한다.
4. 놓친 표도 `그때 그 가격`으로 이야기된다.
5. 이 행동이 쌓여 `이상한 가격을 발견하는 사람들의 클럽`이 된다.

## 2. 마케팅 엔진은 DROP이다

일반적인 운영은 서비스를 만든 뒤 매일 올릴 글을 따로 고민한다.

티키티킷은 반대로 움직인다.

```text
항공권 발견
  → DROP 후보
  → 사이트 사건 카드
  → 공유 이미지
  → 커뮤니티·SNS 속보
  → 네이버 블로그
  → 알림
  → 종료 콘텐츠
  → 지난 DROP
  → 월간·연간 데이터 콘텐츠
```

상품 데이터 하나가 여러 채널의 소재가 된다. 채널별로 새로운 이야기를 억지로 생산하지 않는다.

### DROP의 상태

| 상태 | 의미 | 사용자에게 보이는 것 |
|---|---|---|
| 후보 | 이상한 가격이나 일정이 감지됨 | 아직 공개하지 않음 |
| 발견 | 가격과 예약 가능성을 확인함 | `오늘의 TIKIT DROP` 후보 |
| 진행 중 | 현재 같은 표가 확인됨 | 현재 가격·좌석·확인 시각 |
| 변화 | 가격이나 좌석이 달라짐 | 이전 → 현재 변화 |
| 종료 | 정상 수집에서 더 이상 확인되지 않음 | 종료 시점과 당시 가격 |
| 재등장 | 같은 표가 다시 나타남 | 기존 DROP의 새로운 사건 |
| 전설 | 충분한 기록에서도 드문 사례 | 순위·희소성·이야기 |

DROP 번호는 모든 항공권에 붙이지 않는다. 사람들이 기억할 만한 사건에만 붙인다.

## 3. 첫 화면이 가장 큰 마케팅 채널이다

다른 채널에서 사람을 데려오기 전에, 첫 화면 자체가 캡처하고 싶은 장면이어야 한다.

### 첫 화면의 기본 구조

1. 오늘 가장 강한 DROP 한 장
2. 지금 볼 수 있는 항공권 피드
3. 피드 사이의 가격·일정 사건 카드
4. 목적지 대신 예산과 가능성으로 여는 발견 입구
5. 지난 DROP과 알림으로 이어지는 재방문 장치

정말 미친 표가 발견되면 첫 번째 TIKIT DROP이 화면 대부분을 차지해도 된다. 영웅 카드의 크기를 고정하지 않고 사건의 강도에 맞춘다. 평범한 날에는 목록이 주인공이고, 전설이 될 만한 날에는 그 한 장이 주인공이다.

### 사용할 발견 입구

- 오늘의 TIKIT DROP
- 오늘 가격이 크게 떨어진 표
- 오늘 처음 나타난 가격
- 20만원이면 어디까지?
- 0연차 탈출
- 퇴근 후 출국
- 주말만 다녀올 수 있는 DROP
- 내일 출국 클럽
- 지방공항에서 새로 뜬 표

같은 목적지가 연속으로 보이거나, 모든 카드가 `특가`라고 소리치지 않게 한다.

## 4. DROP을 선정하는 기준

원문의 에너지를 살리려면 평범한 항공권까지 DROP이라고 부르지 않아야 한다.

### 지금 사용할 수 있는 근거

- 직전 관측보다 실제로 가격이 내려감
- 오늘 처음 나타난 표
- 일정과 가격의 조합이 눈에 띔
- 출발이 임박했는데 쓸 만한 시간대임
- 좌석 변화가 확인됨
- 수수료를 고지해도 가격이 매력적임
- 외부 예약 페이지에서 같은 날짜와 표를 확인할 수 있음

### 데이터가 쌓인 뒤 사용할 근거

- 같은 노선·비슷한 여행 시기의 관측 가격 중 드문 위치
- 최근 30일·60일 최저권
- 티키티킷 관측 역사상 순위
- 비슷한 가격의 평균 유지시간
- 좌석 감소와 판매 종료의 관계
- 출발 D-day별 가격 변화

### 후보에서 제외할 것

- 수집 실패 때문에 갑자기 사라지거나 급증한 회차
- 예약 페이지에서 찾을 수 없는 표
- 수수료를 더하면 의미가 사라지는 가격
- 다른 날짜·체류 기간을 섞어 만든 과장된 비교
- 싼 이유를 설명하려면 불편한 시간을 숨겨야 하는 표

### DROP SCORE

원문에는 `DROP SCORE 96`과 `가격 미친놈 지수 93`이 있다. 핵심은 숫자 자체가 아니라 가격 희귀도·출발 임박도·일정의 질을 티키티킷만의 언어로 묶자는 제안이다.

내부 후보 점수로는 사용할 수 있다. 공개 화면에서는 먼저 다음처럼 근거를 풀어 쓴다.

- 최근 관측 중 가장 낮은 가격
- 오늘 42,000원 하락
- 금요일 출발·일요일 귀국
- 출발까지 5일

사용자 반응과 데이터가 충분해지면 공개 지수의 이름과 필요성을 다시 검토한다.

## 5. 공유가 부가 기능이 아니라 제품 흐름이다

서비스 소개글보다 항공권 한 장이 더 강한 광고가 되어야 한다.

### 공유의 출발 문장

- 이거 같이 갈래?
- 야, 우리 이거 가능함.
- 금요일에 갈래?
- 이 가격 실화인지 봐봐.
- 친구 한 명만 구하면 출국.

### 공유 카드에 필요한 것

- 노선
- 왕복 가격
- 출발·귀국 날짜
- 일정이 가능한 이유
- 가격 변화가 있다면 이전 → 현재
- 티키티킷이 마지막으로 확인한 시각

### 공유받은 사람의 화면

같은 항공권 상세를 바로 연다. 끝난 DROP이면 `없어진 상품`으로 끝내지 않고 다음을 보여준다.

- 당시 가격과 일정
- 언제까지 확인됐는지
- 현재 비슷한 항공권
- 같은 조건의 DROP 알림

## 6. 클럽은 기능이 아니라 반복되는 행동에서 시작한다

> **이상한 가격을 발견하는 사람들의 클럽.**

가입 페이지부터 만들지 않는다. 먼저 다음 행동을 가능하게 한다.

- DROP을 공유한다.
- `이 가격이면 간다`에 반응한다.
- 가격과 예약 오류를 제보한다.
- 실제 구매를 인증한다.
- 원하는 가격을 기다린다.
- 지난 DROP을 구경한다.

이 행동이 실제로 생긴 뒤 다음을 붙인다.

- TIKITIKIT CLUB
- 개인 DROP 여권
- 잡은 도시 도장
- 헌터 레벨
- Secret DROP
- DROP REPORT
- CATCH CARD

회원 수보다 `나는 여기서 싸게 여행하는 사람`이라는 정체성이 먼저다.

## 7. 채널 전략

### 1순위 — 티키티킷 자체 화면

가장 강한 DROP과 발견 도구를 제품에 먼저 만든다. 외부에 올릴 이미지도 이 화면에서 나온다.

### 2순위 — 메신저 공유

친구와 여행을 결정하는 실제 대화에 들어간다. 공유 링크 유입이 상세와 예약 클릭으로 이어지는지 측정한다.

### 3순위 — 여행·특가 커뮤니티

사이트 홍보글을 반복하지 않는다. 실제로 이상한 가격이 나왔을 때 항공권 하나를 사실 중심으로 공유한다.

실제 문구와 결과는 [커뮤니티 홍보 실험 기록](community-marketing-experiments.md)에 남긴다.

개발자·창업 커뮤니티에는 수집 구조를 상세히 공개하지 않는다. 여행 수요보다 복제 위험이 크다.

### 4순위 — DROP 속보 계정

여행 팁을 매일 채우는 계정이 아니다.

> 여행 꿀팁 계정을 만들 생각은 없습니다.
>
> 이상하게 싼 항공권이 뜨면 그것만 올리겠습니다.

> **이상한 가격이 떴을 때만 알려주는 계정.**

Threads나 한 개의 짧은 채널부터 시작한다. DROP이 없으면 올리지 않는다.

실제 게시용 말투와 문장 후보는 [Threads 문구 후보](threads-copy-candidates.md)에서 꺼내 쓰되, 가격·일정·예약 가능 여부는 게시 직전에 다시 확인한다.

### 5순위 — 네이버 블로그

현재의 DROP을 검색 가능한 맥락으로 바꾼다.

- 이 가격이 왜 눈에 띄는가
- 실제로 쓸 수 있는 일정인가
- 수수료와 불편은 무엇인가
- 어떤 사람에게 맞는가
- 끝났다면 현재 대안은 무엇인가

상품이 끝나도 글을 삭제하지 않고 종료 상태와 다음 DROP을 보여준다.

### 6순위 — 자체 `/tips`

티키티킷 데이터만으로 쓸 수 있는 글을 만든다.

- 후쿠오카 항공권은 얼마면 사야 할까?
- 출발 며칠 전에 가격이 가장 많이 떨어질까?
- 올해 20만원 이하 도쿄 항공권은 몇 번 나왔나?
- 일본 땡처리 항공권이 가장 많이 뜨는 요일
- 2026년 가장 큰 DROP TOP 20

### 7순위 — TIKIT DROP ALERT

`특가 상품 안내`가 아니라 새로운 사건을 통보한다.

```text
조건에 맞는 티켓이 떴습니다.
후쿠오카 187,000원
금요일 출발 · 일요일 귀국
```

같은 노선과 비슷한 가격을 반복해서 보내지 않는다.

## 8. 원문 아이디어 전체 실행 목록

아래 아이디어는 완성도를 이유로 삭제하지 않는다. 필요한 데이터와 사용자가 생기는 순서에 따라 시험한다.

### A. 지금 작은 형태로 시험할 수 있는 것

| 원문 아이디어 | 핵심 장면 | 첫 실험 |
|---|---|---|
| 오늘의 TIKIT DROP | 하루의 가장 강한 사건에 번호 부여 | 관리자가 확인한 1건을 미리보기와 공유 카드로 제작 |
| 오늘 가장 미친 항공권 단 하나(원문명) | 수백 개보다 오늘의 한 장을 먼저 보게 함 | `오늘의 미친놈` 거대 영웅 카드 시안 |
| 가격 오류 수배령(원문명) | 믿기 어려운 가격을 긴급 사건으로 취급 | 실제 예약 확인을 통과한 후보 한 건에만 임시 배너 적용 |
| 목적지 없는 버튼 | `어디든 싸면 간다` | 현재 가장 싼 3개를 한 화면에 보여줌 |
| 20만원 들고 어디까지? | 목적지 대신 지갑으로 탐색 | 20·30·40만원 버튼과 현재 도시 목록 |
| 퇴근 후 출국 | 금요일 저녁 출발과 주말 귀국 | 실제 시간 조건을 만족하는 표만 모음 |
| 0연차 탈출 | 연차 없이 가능한 여정 | 한 개 항공권에 일정 타임라인 적용 |
| 내일 출국 클럽 | D-0~D-3의 극단적인 발견 | 필터 또는 별도 인사이트 카드로 시작 |
| 이 가격이면 간다 투표 | 가격 하나가 대화가 됨 | 상세에 `간다 / 더 본다` 두 선택지 |
| 친구 한 명만 구하면 출국 | 공유가 일정 제안이 됨 | `금요일에 갈래?`가 포함된 공유 화면 |
| 이 가격, 진짜임? | 신뢰를 캡처 가능한 화면으로 만듦 | 마지막 확인 시각과 예약 페이지 버튼을 한 화면에 표시 |
| DROP 속보 계정 | 특가가 있을 때만 발행 | 하나의 채널에서 수동으로 3건 시험 |
| 사장님 몰래보기 모드 | 사이트가 `2026 Q3 비용정산표` 같은 화면으로 변하고 실제 가격은 표의 숫자로 숨음 | 현재 항공권 데이터를 쓰는 별도 미리보기 한 장으로 공유 반응 확인 |
| 티키티킷 야간상황실 | 금요일 저녁 1~2시간 동안 가격 발견을 실시간 연속 중계 | 강한 DROP이 있는 날에만 Threads 한 회 수동 운영 |
| 실종 항공권 신고 | 싸게 나온 표가 없는 상태 자체를 사건으로 만듦 | 충분한 관측 기록이 있는 한 노선에 `특가가 N일째 실종 중` 게시물 제작 |
| 도망가(원문명) | `월요일입니다. 도망갈 곳 찾아봤습니다.`처럼 여행을 탈출 행동으로 말함 | 서비스명 변경이 아닌 콘텐츠 시리즈명·CTA로 한정해 반응 시험 |

## 9. 대화 원문의 상세 예시 보관

아래 숫자와 항공권은 모두 **가상 예시**다. 현재 사실처럼 발행하지 않는다.

### 거대한 오늘의 미친놈

```text
담당자가 미쳤어요
오늘의 미친놈
TIKIT DROP #142
인천 → 후쿠오카
129,000원
오늘 42,000원 하락
아직 살아있음
[잡으러 가기]
```

진짜 강한 표가 나왔을 때는 이 카드가 첫 화면을 크게 차지한다.

### 오늘의 TIKIT DROP이 살아 있다가 끝나는 장면

```text
TIKIT DROP #043
인천 → 오사카
왕복 164,200원
평소 대비 -47%
현재 23분째 생존 중
```

```text
TIKIT DROP #043 종료
2시간 17분 생존
최저가 164,200원
1,842명 확인
잡은 사람 11명
```

`생존 중`, `잡은 사람`은 실제 확인 주기와 구매 인증이 생긴 뒤에만 공개한다.

### 가격 붕괴 카드

```text
128,900원

▼ 29.3%
최근 60일 중 최저가 1위
```

## 10. 데이터는 마케팅의 원료이지 캐치프레이즈가 아니다

가격·좌석·발견·종료·재등장 기록은 다음을 만들기 위해 필요하다.

- DROP의 이유
- 가격 붕괴 카드
- 역대 순위
- 생존시간
- 지난 DROP
- 데이터 콘텐츠
- 기다릴까, 살까
- 여행사 수요 리포트

공개 브랜드가 `우리는 데이터를 기록합니다`라고 말할 필요는 없다. 사용자가 봐야 하는 것은 기록 자체가 아니라 기록이 만든 놀라운 장면과 믿을 만한 판단이다.

## 11. 지표

### 앞으로 6개월의 세 가지 중심 지표

원문의 우선순위를 따른다.

1. 가격 생애 데이터 누적량과 정상 기록률
2. DROP 알림 등록자
3. 재방문율

### 제품과 마케팅 지표

| 질문 | 지표 |
|---|---|
| DROP이 눈에 띄었나? | 노출 대비 상세 열람률 |
| 친구에게 보내고 싶었나? | 공유율·공유 링크 신규 유입 |
| 실제 구매 관심이 있었나? | 상세 대비 여행사 예약 클릭률 |
| 다시 보러 왔나? | 7일·30일 재방문, 직접 유입 |
| 다음 DROP을 기다리나? | 알림 등록과 클릭 |
| 가격을 믿을 수 있었나? | 가격 차이·예약 불가 신고율 |
| 지난 사건도 가치가 있나? | 지난 DROP에서 현재 표로 이동률 |

조회수가 높아도 공유·예약·재방문이 없으면 브랜드가 아니라 구경거리였을 수 있다.

### 실험 방식

트래픽이 적은 초기에는 정교한 A/B 테스트 결과를 가장하지 않는다.

- 서로 다른 강한 시안을 실제 화면으로 만든다.
- 일정 기간 순차적으로 노출한다.
- 클릭뿐 아니라 공유 문구, 신고, 직접 반응을 함께 본다.
- 충분한 표본이 생기면 A/B 테스트로 전환한다.

## 12. 실행 순서

### 지금 — DROP을 실제 제품으로 만든다

- 생애 기록이 정상적으로 쌓이는지 확인
- 수집 실패를 종료 사건에서 제외
- 인사이트바를 실제 가격 사건으로 변경
- 편집 카드와 SNS에 쓰는 사건 제목을 인사이트바에도 그대로 사용한다. 별도의 평범한 `사이트용 제목`을 만들지 않고, 아래 노선·가격·시간이 제목의 근거를 증명하게 한다.
- 제목은 완성형 광고 문장이 아니라 사건을 옮겨 붙인 짧은 스티커·상태 라벨로 쓴다. `🚨 가격 붕괴 감지`, `🏃 0연차 탈출 가능`처럼 제목은 짧게 끊고, 바로 아래 가격·시간·노선이 근거를 증명한다.
- 뜻이 모호한 `가격이 도망쳤습니다`, 평범한 `오늘 가격이 크게 떨어졌어요`, 사실만 나열하는 `기타큐슈, 갑자기 6.4만원 싸졌습니다`는 사용하지 않는다.
- 오늘의 TIKIT DROP 후보를 관리자에서 확인
- 가격 변화 공유 카드 시안 제작
- `20만원이면 어디까지?`와 `0연차 탈출` 작은 시안 제작
- 공유 링크 유입 측정

### 인사이트바 운영 규칙

- 첫 16개 항공권 카드 사이에는 2개, 한 번의 탐색 흐름 전체에는 최대 5개만 노출한다.
- 최대 구성은 `가격·기록 사건 2 + 실제로 가능한 여행 2 + 낯선 목적지 발견 1`이다. 후보가 없으면 수를 채우지 않는다.
- 같은 목적지와 같은 종류는 한 번씩만 노출하고, `붕괴·미친·유니콘` 같은 강한 라벨은 한 화면에 하나만 쓴다.
- 목적지 소개는 연속으로 나열하지 않고 최대 1개만 노출한다. 제목은 `🧭 요나고 입문`처럼 짧게, 본문은 위치·여행 성격·주의점 중 가장 유용한 한 가지만 보여준다.
- 자체 생애 기록이 없으면 `좌석 5개 증발`, `실종 가격 재등장`처럼 상품 변화를 암시하는 제목은 쓰지 않는다.

현재 사용하는 제목 도구함:

- 가격: `💸 6.4만원 증발`, `🚨 가격 붕괴 감지`, `🧨 20만원선 붕괴`, `💥 예산선 파괴`, `🔻 오늘 최저가 갱신`, `🏆 최근 60일 최저가`, `🏆 올해 최저가 TOP 3`, `🦄 유니콘보다 드문 가격`
- 일정: `🏃 0연차 탈출 가능`, `🌙 퇴근 후 출국`, `🥱 귀국 다음 날 위험`, `🌙 가격 좋음 · 시간 험함`, `🧳 주말 압축 성공`
- 비교: `🛅 오늘은 부산보다 인천`, `🚄 청주까지 갈 이유`, `💰 공항 바꾸고 14.5만원 SAVE`
- 새 발견: `🎟 새 일정 투하`, `🆕 새 DROP 등장`, `🧭 요나고 입문`
- 생애 기록 축적 뒤 사용: `👻 실종 가격 재등장`, `🔥 좌석 5개 증발`, `🪑 마지막 4석 생존`
- 매우 드문 사건에만 사용: `🤯 정상 가격 맞나요`, `🩺 가격표 응급상황`, `🧨 DROP 임계점 돌파`, `🫣 담당자 확인 전`, `🤯 담당자가 미쳤어요`

### 3~6주 — 끝난 DROP도 콘텐츠로 만든다

- 지난 DROP 목록과 상세
- 종료·재등장 표시
- DROP 번호 운영 기준
- 한 개 커뮤니티와 한 개 속보 채널에서 실제 사건 배포
- `이 가격, 진짜임?` 검증 화면 실험

### 2~3개월 — 데이터가 보이기 시작한다

- 같은 노선·비슷한 여행 시기의 비교 기준
- 가격 붕괴 카드
- 최근 30일·60일 위치
- 티키티킷 역대 순위의 최소 표본 결정
- 첫 데이터 기반 `/tips` 글

### 3~6개월 — 클럽과 전설을 만든다

- 전설의 DROP 박물관
- 구매 인증과 CATCH CARD
- 티키티킷 여권
- DROP REPORT
- 연말 TIKIT DROP AWARDS 준비
- 여행사 수요 리포트 가능성 검토

### 충분한 수요 이후

- Secret DROP
- EXCLUSIVE TIKIT DROP
- 기다릴까, 살까
- HOTEL DROP과 TRIP DROP

아이디어를 버리지 않되 데이터와 사람이 없는 상태에서 껍데기만 먼저 만들지 않는다.

|---|---|---|
| 크롤링 후 | 가격·좌석 변화와 후보 추출 | 이상 급증·급감과 예약 가능성 확인 |
| DROP 후보 발생 | 카드·문구·공유 이미지 초안 | 공개할 사건과 표현 결정 |
| 종료 확인 | 지난 DROP 초안 생성 | 실제 종료인지 확인 |
| 주 1회 | 유입·상세·예약·공유·알림 집계 | 다음에 시험할 장면 선택 |
| 월 1회 | 노선·가격·좌석 변화 집계 | 데이터 콘텐츠 선정 |

DROP이 없으면 평범한 표를 억지로 선정하지 않는다. 반대로 강한 사건이 생기면 정해진 발행일까지 기다리지 않는다.

---

## 14. 하지 않을 것

- 여러 여행상품을 빠르게 붙여 종합 플랫폼처럼 보이기
- 매일 같은 TOP 3 자동 발행
- 가격과 날짜만 바꾼 SEO 글 대량 생산
- 모든 항공권에 DROP 번호 붙이기
- 구매 확인 없이 잡은 사람 수 표시
- 충분한 데이터 없이 역대 순위·생존 확률 공개
- 모든 SNS 채널 동시 운영
- 서비스 구조와 크롤링 방법을 마케팅 소재로 공개
- 방문자를 남겨둘 장치 없이 유료 광고 집행
- 원문의 거친 표현만 가져오고 제품 경험은 그대로 두기

---

## 15. 전략이 작동하는 신호

- 사용자가 사이트 소개가 아니라 특정 DROP을 공유한다.
- `티키티킷에서 봤다`가 가격 발견의 출처처럼 쓰인다.
- 직접 유입과 재방문이 늘어난다.
- 끝난 DROP도 계속 열리고 현재 표로 연결된다.
- 좋은 가격을 잡은 사용자가 자발적으로 인증한다.
- 다른 콘텐츠가 티키티킷 데이터를 인용한다.
- 여행사가 티키티킷의 대기 수요를 궁금해한다.
- `항공권 검색해야지`보다 `오늘 뭐 떴지?`라는 행동이 보인다.

궁극적으로 사용자가 이렇게 느껴야 한다.

> **다른 서비스는 항공권을 검색한다. 티키티킷은 항공권이 싸지는 순간을 안다.**
