# 티키티킷 마케팅 전략 - Version 2

> 현재 사용하는 실행 전략입니다. 브랜드와 문구는 [브랜드 가이드 Version 2](branding-guide.md)를 따릅니다.
> [Version 1 보관본](marketing-strategy-v1.md)은 이전 논의를 기록하기 위해 남겨두었습니다.

---

## 1. 전략의 결론

티키티킷은 대형 항공권 검색 서비스와 검색 기능의 수로 경쟁하지 않습니다.

대신 다음 상황에서 가장 먼저 떠오르는 서비스를 목표로 합니다.

> **여행은 가고 싶은데 어디로 갈지는 정하지 않았을 때, 지금 싸게 나온 표를 보러 가는 곳.**

마케팅의 역할은 방문자를 많이 모으는 데서 끝나지 않습니다.

1. 저렴한 표를 보러 들어옵니다.
2. 항공권 상세를 확인합니다.
3. 예약하거나 함께 갈 사람에게 보냅니다.
4. 마음에 드는 표가 없으면 조건을 남깁니다.
5. 나중에 새 표가 나오면 다시 돌아옵니다.

이 흐름이 반복되어야 마케팅에 돈과 시간을 더 쓸 이유가 생깁니다.

## 2. 현재 가진 것과 부족한 것

### 이미 가진 것

- 여러 여행사의 땡처리 항공권 데이터
- 가격, 날짜, 항공 시간, 출발 공항, 여행사, 수수료 정보
- 외부 가격 자료를 활용한 내부 검증
- 가격과 정보 확인 시점을 반영한 추천순
- 항공권별 공유 링크와 OG 이미지
- 개별 가격 알림과 출발지·지역·예산 조건형 알림 베타
- GA4 이벤트와 관리자 통계
- 네이버 블로그 자동화 경험과 기존 콘텐츠 자산
- 장기적으로 분석할 수 있는 자체 가격 기록

### 아직 부족한 것

- 방문자가 적어 어떤 메시지와 기능이 효과적인지 판단할 표본이 부족함
- 조건형 알림의 실제 발송과 재방문 성과가 충분히 검증되지 않음
- 매주 꾸준히 운영할 수 있는 콘텐츠 선정 방식이 완성되지 않음
- 공유 링크가 실제 신규 방문과 예약 클릭을 얼마나 만드는지 데이터가 부족함
- 자체 가격 기록을 활용한 `/tips` 콘텐츠를 만들 만큼 데이터가 충분히 쌓였는지 확인이 필요함

### 운영 조건

티키티킷은 사실상 한 사람이 운영합니다. 새로운 채널 하나는 게시물 작성뿐 아니라 댓글, 문의, 오류, 일정까지 늘립니다. 따라서 **채널 수보다 같은 데이터가 여러 곳에서 다시 쓰이는 구조**를 먼저 만듭니다.

## 3. 누구를 먼저 데려올 것인가

### 1순위: 목적지를 정하지 않은 예산 중심 사용자

- “20만원으로 어디까지 갈 수 있지?”
- “지금 갑자기 싸게 나온 곳이 없을까?”
- “아무 데나 좋으니 15만원 아래면 보고 싶다.”

티키티킷의 목록, 추천순, 조건형 알림이 가장 잘 맞는 사용자입니다.

### 2순위: 일정이나 출발지에 제약이 있는 사용자

- “금요일 저녁에 떠나 일요일에 돌아오고 싶다.”
- “부산이나 청주에서 출발하고 싶다.”
- “연차 하루로 다녀올 수 있으면 좋겠다.”

가격만큼 항공 시간과 체류 기간이 중요합니다.

### 3순위: 정확한 목적지와 날짜를 정한 사용자

검색과 외부 가격비교 버튼을 사용할 수 있습니다. 다만 대형 검색 서비스와 가장 직접적으로 겹치는 영역이므로 마케팅의 첫 표적으로 삼지 않습니다.

## 4. 성장 구조

```text
여행사 항공권 수집
    ↓
지금 보여줄 만한 저렴한 표 선정
    ↓
사이트 목록 · 블로그 · 공유 카드 · 커뮤니티
    ↓
항공권 상세 확인
    ↓
예약 클릭 · 공유 · 조건형 알림 등록
    ↓
공유받은 사람의 방문 · 알림을 통한 재방문
    ↓
어떤 가격·일정·목적지가 반응을 얻었는지 학습
    ↓
다음 추천과 콘텐츠 선정 개선
```

같은 항공권 데이터를 제품, 콘텐츠, 공유, 알림이 함께 사용합니다. 매번 채널별로 소재를 새로 만들지 않습니다.

## 5. 가장 중요한 지표

### 중심 지표: 주간 행동 사용자 수

한 주 동안 아래 행동 중 하나 이상을 한 순사용자 수를 봅니다.

- 여행사 예약 페이지 클릭
- 항공권 공유
- 개별 가격 알림 등록
- 조건형 특가 알림 등록

단순 방문자는 포함하지 않습니다. 항공권을 보고 실제 다음 행동으로 간 사람만 셉니다.

### 단계별 지표

| 단계 | 지표 | 알 수 있는 것 |
|---|---|---|
| 목록 | 항공권 상세 확인률 | 첫 화면에서 볼 만한 표를 보여줬는가 |
| 상세 | 예약 클릭률 | 가격과 일정이 실제 관심으로 이어졌는가 |
| 공유 | 공유 클릭률, 공유 링크 유입 | 함께 갈 사람에게 보낼 가치가 있었는가 |
| 알림 | 등록률, 실제 발송률 | 지금 원하는 표가 없는 사람을 남겨두었는가 |
| 재방문 | 알림 클릭률, 7일·30일 재방문률 | 새 표가 다시 방문할 이유가 되었는가 |
| 품질 | 가격 변동·예약 불가 신고율 | 오래되거나 잘못된 표를 줄이고 있는가 |

### 적은 트래픽에서 판단하는 법

- 동시에 여러 실험을 하지 않습니다.
- 한 번에 문구나 배치 하나만 바꾸고 최소 2주를 봅니다.
- 표본이 적으면 작은 차이를 승리로 선언하지 않습니다.
- 숫자와 함께 실제 공유 링크, 신고 내용, 사용자가 자주 본 노선을 확인합니다.
- 방문자 수가 올라도 상세 확인과 예약 클릭이 늘지 않으면 성공으로 보지 않습니다.

## 6. 제품 자체가 하는 마케팅

### 6-1. 첫 화면: 오늘은 어디가 싸게 나왔을까요?

첫 화면은 검색창보다 현재 항공권이 먼저 가치를 보여줘야 합니다.

- 저렴한 표가 먼저 보임
- 같은 목적지가 과하게 반복되지 않음
- 지방공항 출발도 가격과 조건이 좋으면 함께 보임
- 가격을 언제 확인했는지 알 수 있음
- 수수료와 불편한 시간을 숨기지 않음

이 화면이 매일 다시 들어올 이유가 됩니다.

### 6-2. 상세 화면: 이 표를 살지 판단하는 곳

상세 화면은 여행 정보를 길게 읽는 곳이 아닙니다. 다음 정보를 빠르게 확인하는 곳입니다.

- 왕복 가격
- 출발·귀국 날짜와 시각
- 실제 체류 기간
- 항공사와 여행사
- 수수료와 가격 변동 가능성
- 예약, 공유, 알림 버튼

### 6-3. 공유: “이거 같이 갈래?”를 쉽게 만들기

공유 버튼은 카드와 상세에 모두 둘 수 있지만 같은 상세 링크를 사용합니다.

공유 미리보기에는 다음 정보가 보여야 합니다.

- 출발지와 목적지
- 왕복 가격
- 날짜
- 목적지 이미지

공유 링크를 열면 해당 항공권 상세가 바로 열립니다. 항공권이 사라졌다면 빈 화면 대신 같은 노선이나 가까운 현재 표를 보여줍니다.

카카오 공식 공유 기능은 일반 링크 공유의 성과가 확인된 뒤 검토합니다. 먼저 지금 있는 공유 링크가 실제 유입을 만드는지 측정합니다.

### 6-4. 조건형 알림: 검색하지 않은 새 표를 데려오기

첫 설정은 세 가지만 받습니다.

- 출발지
- 가고 싶은 지역 또는 아무데나
- 예산

조건은 후보를 고르는 기준일 뿐입니다. 예산 이하라는 이유만으로 전부 보내지 않습니다. 가격과 일정이 충분히 눈에 띄고 최근 같은 내용을 보내지 않았을 때만 알립니다.

현재 이용자가 적으므로 발송량 확대보다 후보가 제대로 선택되는지 관리자 화면에서 먼저 확인합니다.

## 7. 콘텐츠 전략

### 기본 원칙

콘텐츠는 실제로 나온 항공권에서 시작합니다. 발행 일정을 채우기 위해 표를 억지로 고르지 않습니다.

좋은 콘텐츠는 실제 표를 보고 생기는 질문에 답합니다.

1. 얼마인가?
2. 언제 떠나고 돌아오는가?
3. 이 가격과 일정이 왜 눈에 띄는가?
4. 미리 알아야 할 비용이나 불편은 무엇인가?
5. 이 표가 잘 맞는 사람은 누구인가?

항공사나 목적지가 생소하다면 독자가 궁금해할 사실을 덧붙입니다. 위치와 공항 이동 시간만으로 제한하지 않으며, 그 표로 가능한 여행을 상상하게 만드는 정보라면 충분히 설명할 수 있습니다. 다만 항공권과 연결되지 않은 일반 여행 정보로 글을 채우지는 않습니다.

이 질문들을 매번 체크리스트처럼 같은 순서와 분량으로 쓰지 않습니다. 내부에서는 가격, 일정, 불편, 흥미 요소, 잘 맞는 여행자를 꼼꼼히 확인하되, 공개 글에서는 그 표가 재미있는 이유를 자연스럽게 이야기합니다.

### 운영할 콘텐츠 묶음

#### A. 예산으로 보는 표

- `20만원으로 갈 수 있는 실제 항공권`
- `인천 출발 15만원 아래에 새로 나온 곳`
- `부산에서 20만원으로 갈 수 있는 일본`

#### B. 일정으로 보는 표

- 실제 항공 시간이 맞을 때만 `연차 없이 가능한 일정`
- `연차 하루로 가능한 3박 4일`
- `금요일 저녁 출발 표`

새벽편이라는 이유만으로 제외하지 않습니다. 목적지에서 쓸 수 있는 시간을 보고 판단합니다.

#### C. 처음 보는 표

- 익숙하지 않지만 저렴하고 일정이 괜찮은 노선
- 어느 지역인지, 어떻게 들어가는지, 이 일정으로 무엇을 즐길 수 있는지 가운데 그 표를 궁금하게 만드는 정보를 선택해 설명
- `가볼 만할까?`, `어떤 곳일까?` 같은 제목은 반복하지 않음

#### D. 지방공항 출발

- 부산, 대구, 청주, 제주에서 새로 나온 저렴한 표
- 수도권 출발을 억지로 줄이지 않고 실제 데이터가 좋을 때 함께 보여줌

#### E. 티키티킷 드롭

- 매일 정해진 시각에 무조건 만들지 않음
- 한 주에 소개할 가치가 있는 표가 모였을 때 대표 3개를 선정
- 단순 최저가가 아니라 가격, 날짜, 시간, 희소성을 함께 봄
- 사이트, 블로그, 공유 카드에서 같은 항공권을 사용
- 제목은 세 항공권을 기계적으로 나열하기보다 이번 드롭을 열어볼 이유를 먼저 보여줌
- 보통은 가장 강한 사실을 앞세우되, 목적지 이름이나 여러 표의 조합이 검색과 흥미에 도움이 되면 제목에 함께 쓸 수 있음
- 모호한 낚시 문구와 클릭 전에 내용을 모두 설명하는 제목 사이에서, 구체적인 이득과 남겨둘 궁금증의 균형을 잡음
- 의미 없는 상투적 도입은 생략하지만, 새로운 노선이나 뜻밖의 일정처럼 읽을 이유가 분명한 도입은 자유롭게 사용함
- 세 항공권의 분량과 순서를 똑같이 맞추지는 않음. 가장 강한 표가 앞에 설 수 있지만, 나머지도 고른 이유와 판단할 조건을 충분히 보여줌
- 내부에서는 가격 메리트, 일정의 질, 숨은 비용과 불편, 흥미로운 사실, 잘 맞는 여행자를 확인하고 외부에서는 딱딱한 평가표가 아니라 읽히는 이야기로 바꿈
- 가격·수수료·운항·목적지 정보는 발행 시점에 다시 확인하고, 확인된 범위보다 넓게 해석하지 않음

### 네이버 블로그와 `/tips`의 역할

**네이버 블로그**는 지금 나온 표로 현재 방문을 만듭니다.

- 새로 나온 저렴한 표
- 이번 주 실제로 가능한 일정
- 지방공항 출발
- 처음 보는 목적지

**`/tips`**는 시간이 지나도 검색되는 자체 데이터 콘텐츠를 만듭니다.

- 출발 며칠 전에 가격이 변했는지
- 노선별·월별 가격 기록
- 실제로 수집된 표의 가격 분포
- 현재 표로 이어지는 링크

가격 기록이 충분하지 않으면 통계를 서둘러 만들지 않습니다. 일반 여행 상식을 채워 넣어 페이지 수만 늘리지 않습니다.

### 발행하지 않을 콘텐츠

- 매일 오후 4시에 자동 생성되는 고정 TOP 3
- 날짜와 가격만 바뀌는 글
- 전형적인 AI 제목과 결론
- 항공권과 관계없는 맛집·관광지 모음
- 검증하지 않은 최저가와 긴급성
- 읽을 만한 표가 없는데도 발행하는 글

## 8. 채널 우선순위

### 1순위: 티키티킷 자체 화면

가장 먼저 고쳐야 할 채널입니다. 다른 곳에서 사람을 데려와도 목록과 상세가 설득하지 못하면 모두 나갑니다.

### 2순위: 검색

- 네이버 블로그: 지금 나온 표와 현재 검색 수요
- 사이트 `/tips`: 자체 가격 데이터가 쌓일수록 강해지는 장기 검색 자산
- 두 곳에 같은 글을 복사하지 않음

### 3순위: 공유

카카오톡과 단체 대화방에서 항공권 자체가 퍼지게 합니다. 서비스 소개글보다 구체적인 노선·가격·날짜가 더 강한 광고가 됩니다.

### 4순위: 여행 커뮤니티

서비스 홍보글을 정기적으로 올리지 않습니다. 실제로 소개할 가치가 있는 표가 있을 때만 가격과 일정을 정리해 공유합니다. 각 커뮤니티 규정을 먼저 확인합니다.

### 5순위: 자체 알림

조건형 알림은 사용자가 늘기 전에 발송 품질을 검증합니다. 알림이 반복 방문과 예약 클릭을 만든다는 것이 확인되면 가장 중요한 재방문 채널이 됩니다.

### 나중에 검토할 채널

- 카카오톡 채널: 자체 알림 성과와 구독자가 쌓인 뒤
- 짧은 영상: 기존 콘텐츠 중 반응이 좋은 소재가 반복해서 확인된 뒤
- 유료 광고: 알림 등록 또는 예약 클릭으로 이어지는 경로가 검증된 뒤

### 지금 하지 않을 것

- 카카오 오픈채팅방 운영
- 모든 SNS 동시 운영
- 비싼 항공권 검색 광고
- 방문자를 남겨둘 장치 없이 유료 광고 집행
- 외부 가격 크롤링을 홍보 소재로 사용

## 9. 12주 실행 계획

### 1~2주: 기준과 측정 고정

- Version 2 문구를 사이트의 헤더, 검색 설명, 푸터, 알림 진입에 일관되게 반영
- GA4에서 목록 조회 → 상세 → 예약·공유·알림 흐름이 끊기지 않는지 확인
- 관리자 화면에서 여행사·노선·예약 클릭을 주간 단위로 볼 수 있게 정리
- 공유 링크가 정확한 항공권 상세를 여는지 모바일과 PC에서 확인
- 현재 지표를 기준선으로 저장

### 3~6주: 콘텐츠 형식 검증

- 주 1~2회, 소개할 가치가 있는 표가 있을 때만 글 작성
- 예산·일정·지방공항·처음 보는 표 형식을 번갈아 사용
- 모든 글에 항공권별 공유 링크와 측정값을 붙임
- 제목과 썸네일은 한 번에 한 가지 형식만 바꿔 최소 2주 관찰
- 조회수보다 상세 확인과 예약 클릭을 비교

### 7~10주: 공유와 알림 검증

- 자주 공유되는 가격대·목적지·여행기간 확인
- 공유받은 사람이 상세를 열고 예약을 누르는지 확인
- 조건형 알림 후보를 관리자 화면에서 수동 검수
- 실제 발송 시 같은 지역 반복, 애매한 가격, 불편한 일정을 걸러냄
- 알림 클릭과 재방문을 기록

### 11~12주: 집중할 한 가지 선택

아래 가운데 실제 예약 클릭과 재방문을 가장 많이 만든 하나를 다음 분기의 중심으로 선택합니다.

- 검색 콘텐츠
- 공유
- 조건형 알림
- 커뮤니티 특가 공유

성과가 없는 채널은 관성으로 유지하지 않습니다.

## 10. 주간 운영 방식

| 주기 | 할 일 | 목적 |
|---|---|---|
| 매일 자동 | 항공권 수집, 가격 확인, 추천순 갱신, 알림 후보 생성 | 데이터 유지 |
| 주 1회 | GA4·관리자 통계에서 상세·예약·공유·알림 확인 | 다음 실험 결정 |
| 주 1~2회 | 실제로 소개할 표가 있을 때 콘텐츠 작성 | 검색과 공유 유입 |
| 좋은 표 발견 시 | 커뮤니티 규정에 맞춰 항공권 1건 공유 | 초기 사용자 확보 |
| 월 1회 | 채널별 투입 시간과 행동 사용자 수 비교 | 운영 낭비 제거 |

### 자동화할 것

- 콘텐츠 후보 추출
- 가격·날짜·항공 시간 정리
- 공유 이미지 초안
- 링크와 측정값 생성
- 조건형 알림 후보 생성

### 사람이 확인할 것

- 정말 소개할 만큼 좋은 표인지
- 제목이 흔한 AI 문장처럼 보이지 않는지
- 항공 시간과 체류 기간을 잘못 해석하지 않았는지
- 생소한 목적지 설명이 사실인지
- 글이 같은 도입과 순서를 반복하는 양식처럼 보이지 않는지
- 각 항공권을 고른 이유가 충분히 드러나는지
- 단점을 숨기지 않되 제목부터 흥미를 꺾는 방식으로 과장하지 않았는지
- 발행 또는 알림 전송 여부

## 11. 수익과 마케팅의 관계

마케팅은 예약 클릭이 늘어도 사용자 신뢰를 해치지 않아야 합니다.

- 제휴 수익이 있는 마이리얼트립 항공권이라고 추천 순위를 올리지 않습니다.
- 제휴 링크가 있는 곳에는 알아볼 수 있게 표시합니다.
- 다른 여행사는 직접 수수료를 주지 않을 가능성을 전제로 합니다.
- 예약 클릭과 사용자가 충분히 쌓인 뒤 eSIM, 여행자보험, 숙소 같은 부가 제휴를 검토합니다.
- 부가 제휴는 항공권 선택을 방해하지 않는 상세 화면 이후에 둡니다.
- 광고나 협찬 콘텐츠는 일반 추천과 구분합니다.

초기 수익보다 먼저 증명할 것은 `좋은 표를 보여줌 → 상세 확인 → 예약 클릭`이 반복되는가입니다.

## 12. 전략이 잘못되고 있다는 신호

- 사이트 설명은 많아지는데 항공권 상세 확인은 늘지 않음
- 여행 정보가 가격과 항공 시간보다 더 크게 보임
- 블로그 글은 늘지만 사이트 방문과 예약 클릭이 없음
- 같은 목적지와 같은 제목이 반복됨
- 알림은 많이 보내지만 클릭과 재방문이 줄어듦
- 공유 버튼은 눌리지만 공유받은 사람이 상세를 열지 않음
- 유료 광고로 방문만 늘고 알림 등록과 예약 클릭은 그대로임
- 운영 채널이 늘어 한 주의 데이터를 확인할 시간이 없어짐

이 신호가 보이면 콘텐츠 수나 기능 수를 늘리지 말고 목록, 상세, 공유, 알림의 품질부터 다시 봅니다.

## 13. 다음 결정을 위한 질문

매주 다음 질문에 답합니다.

1. 이번 주에 사람들이 가장 많이 상세를 연 표는 무엇이었나?
2. 가장 많이 예약 사이트로 이동한 표는 무엇이었나?
3. 가격만 낮고 클릭되지 않은 표에는 어떤 문제가 있었나?
4. 어떤 항공권이 공유되었고 공유받은 사람도 들어왔나?
5. 조건형 알림 신청자는 어떤 출발지·지역·예산을 원했나?
6. 가격 변동과 예약 불가 신고가 반복된 여행사는 어디인가?
7. 다음 주에는 무엇 하나만 바꿔볼 것인가?
