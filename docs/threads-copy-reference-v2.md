# 티키티킷 Threads 문장 참고본 — Version 2

> **상태: 2026-08-26 현재 사용.**
> **출처 범위:** 이 대화에서 사용자가 직접 제공하거나 다시 승인한 문장과 지시만 반영했다. 사용 보류된 브랜딩·마케팅·DROP 문서와 예전 대화는 독립적인 기준으로 참고하지 않는다. 사용자가 붙여넣은 내용 안의 중복은 강조로 해석하지 않고 한 번만 반영한다.
> 이전 문서 `docs/threads-copy-candidates.md`는 롤백용으로 보존한다.

## 1. 이 문서의 역할

이 문서는 게시할 문장을 골라 쓰는 목록이 아니다.

기존 문장은 티키티킷 Threads의 캐릭터, 길이, 숫자 사용법, 흥분의 정도를 확인하는 참고 사례다. 실제 게시물은 현재 항공권에서 눈에 띄는 사실을 찾아 매번 새로 만든다.

도시와 가격만 바꿔 같은 문장을 다시 쓰지 않는다.

## 2. 계정의 목적

> 티키티킷 Threads의 목적은 항공권을 많이 올리는 게 아니라 “항공권 가격을 매일 들여다보는 이상한 사람”이라는 캐릭터를 만드는 것.

## 3. 문체 원칙

1. 흥분은 하되 호들갑은 짧게.
2. 설명은 숫자로.
3. 회사 말투 말고 사람이 말하는 것처럼.
4. 링크보다 먼저 친구한테 보내고 싶은 한 문장을 만든다.

## 5. SNS용 짧은 반응 훅

아래 문구는 2026-08-26 대화에서 사용자가 직접 골랐다. 웹사이트 TIKIT DROP 카드의 상단 보조 라벨에는 사용하지 않고, Threads·Instagram 등 SNS에서 실제 항공권을 본 반응으로 자연스러울 때만 사용한다.

자동 로테이션하거나 도시·가격만 바꿔 반복하는 완성 원고가 아니다. 게시물의 첫 반응, 이미지 헤드라인 또는 짧은 답글 후보로만 활용하고, 실제 표와 어울리지 않으면 사용하지 않는다.

## 6. 새 문장을 만들 때

1. 실제 항공권에서 가장 먼저 친구에게 말하고 싶은 사실 하나를 고른다.
2. 가격, 날짜, 시간, 여행기간, 가격 변화 중 확인된 숫자를 사용한다.
3. 같은 사실을 몇 가지 방식으로 말해보고 가장 자연스러운 첫 문장을 고른다.
4. 기존 문장과 표현이나 결말이 너무 비슷한 안은 버린다.
5. 게시 직전에 가격, 일정, 왕복 여부, 예약 가능 여부를 다시 확인한다.
6. 순위·평균·백분위·하락률·유지시간은 이를 계산할 실제 관측 데이터가 있을 때만 쓴다.
7. 새 문장은 게시했거나 사용자가 좋다고 승인했을 때만 이 문서에 추가한다.

기존 문장을 잘 재현하는 것이 목표가 아니다. 같은 사람이 새로운 상황을 보고 새롭게 말하는 것이 목표다.
