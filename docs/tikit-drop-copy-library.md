# 웹사이트 TIKIT DROP 카드 문구

> 2026-08-26 기준으로 사용자가 직접 고른 웹사이트용 TIKIT DROP 카드 문구를 정리한 문서다.
> 아래 문구는 일반 항공권 카드, 인사이트바, SNS 게시물, 블로그 제목에 임의로 사용하지 않는다. 티키티킷이 TIKIT DROP으로 선정한 항공권 카드 안에서, 그 표를 선정한 이유를 보여주는 용도로 사용한다.
> `상단 롤링 경보 띠 전용`에 따로 적은 문구만 실제 DROP 경보가 켜졌을 때 상단 롤링 바에서 사용한다.

## 현재 메인 카드 운영 원칙

- 메인은 SNS보다 신뢰와 땡처리 항공권 전문성을 먼저 보여준다.
- TIKIT DROP은 전체 목록의 첫 카드 하나만 강조하고, 따로 상단 영역으로 옮기지 않는다.
- 카드 하단은 반응형 농담보다 선정 근거를 먼저 보여준다. 월평균가 비교가 가능하면 `동일 목적지 월평균가 대비 ↓ {n}%`를 한 문장으로 표시하고, 할인율에 따로 뱃지는 쓰지 않는다.
- 입증할 평균가가 없으면 확인된 남은 좌석 수를 표시하고, 둘 다 없으면 `가격·일정을 비교해 고른 표`로 표시한다.
- 아래 캐릭터 문구는 보존하되 현재 메인 DROP 카드의 기본 문구로는 사용하지 않는다.

## 문구 운용 원칙

- 한 TIKIT DROP 카드에는 상황과 실제 데이터에 맞는 문구 하나만 사용한다.
- 한 번 노출한 문구는 사이트 전체를 기준으로 우선 14일 동안 다시 사용하지 않는다.
- 문구 사용 이력은 방문자 브라우저별로 나누지 않고 사이트 공통 기록으로 남긴다.
- 같은 조건의 문구가 여러 개라면 최근에 가장 오래 사용하지 않은 문구를 우선한다.
- 14일 안에 사용할 수 있는 적합한 문구가 모두 소진되면 조건에 맞지 않는 문구를 억지로 사용하지 않고, 가장 오래전에 사용한 적합 문구부터 다시 사용한다.
- 가격·좌석·일정 조건이 달라지면 기존 문구를 그대로 유지하지 않고 현재 데이터에 맞는 문구를 다시 고른다.

## 카드 문구 적용 조건

- `{하락액}`, `{절약액}`, `{n}`, `{출발시간}`, `{목적지}`, `{출발지A}`, `{출발지B}`는 실제 항공권 데이터로 치환한다.
- `부산 갈 돈으로 {목적지}`는 표시 가격이 17만원 미만인 항공권에만 사용한다.
- D-day 문구는 출발이 얼마 남지 않은 항공권에만 사용하고, `{n}`에는 실제 남은 일수를 넣는다.
- 가격 하락, 최저가, 재등장, 좌석 감소, 공항 변경 절약액처럼 과거 기록이나 비교가 필요한 문구는 이를 입증할 데이터가 있을 때만 사용한다.
- 좌석 수는 실제로 확인된 경우에만 표시한다.
