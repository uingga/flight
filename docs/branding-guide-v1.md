# 티키티킷 브랜드 가이드 - Version 1 (보관본)

> 이 문서는 이전 논의를 보관한 자료입니다. 현재 기준은 [브랜드 가이드 Version 2](branding-guide.md)입니다.
> 이 문서는 제품 화면, 기능 기획, 알림, 콘텐츠, 공유 문구, 제휴 안내 등 사용자가 티키티킷을 경험하는 모든 접점의 기준입니다.
> 작성 당시 브랜드 방향은 [티키티킷 홍보·마케팅 전략 원문 모음](티키티킷_홍보_마케팅_전략_원문_모음.docx)과 [마케팅 전략 Version 1](marketing-strategy-v1.md)을 참고했습니다.

## 0. 브랜드 나침반

### 한 줄 정의

> **티키티킷은 사용자가 직접 찾지 않아도, 저렴한 땡처리 항공권을 먼저 보여주는 서비스입니다.**

### 모든 기능의 첫 질문

> **“항공권 검색을 더 편하게 하는가?”보다 “새로운 여행 기회를 더 잘 발견하게 하는가?”를 먼저 묻습니다.**

검색 편의 기능이 불필요하다는 뜻은 아닙니다. 다만 제품과 마케팅의 우선순위는 다음 순서로 정합니다.

1. 사용자가 몰랐던 저렴한 표를 보여주는가?
2. 날짜와 시간까지 보고 고를 수 있게 하는가?
3. 마음에 드는 표를 바로 예약하거나 공유할 수 있는가?
4. 지금 맞는 표가 없다면 조건형 알림이 새 표를 대신 찾아주는가?
5. 위 네 가지와 관계가 약할 때 일반적인 검색 편의성 개선으로 평가한다.

### 티키티킷이 만들고 싶은 순간

기존 항공권 검색은 보통 `목적지·날짜 결정 → 검색 → 가격 비교`로 시작합니다. 티키티킷은 `저렴한 표 확인 → 갈 곳 발견 → 날짜와 시간 확인 → 예약·공유`의 순서를 만듭니다.

목표는 검색 단계를 줄이는 데서 끝나지 않습니다. **계획에 없던 여행이 실제 계획이 되게 하는 것**입니다.

## 1. 우리는 무엇이고, 무엇이 아닌가

| 티키티킷은 | 티키티킷은 아니다 |
|------------|-------------------|
| 저렴한 땡처리 항공권을 먼저 보여주는 서비스 | 대형 항공권 검색 서비스의 축소판 |
| 가격을 먼저 보되 날짜와 시간도 함께 보는 서비스 | 가격만으로 순위를 매기는 목록 |
| 생소한 목적지도 조건이 좋으면 보여주는 서비스 | 익숙한 인기 도시만 반복하는 순위표 |
| 필요한 정보만 쉽게 보여주는 서비스 | 내부 점수와 비교 데이터를 과시하는 분석 도구 |
| 지금은 예약·공유로, 나중에는 조건형 알림으로 이어지는 서비스 | 조급함을 만들어 클릭을 강요하는 판매원 |

티키티킷은 먼저 가격을 봅니다. 다만 가격만으로 순서를 정하지 않습니다. 날짜와 시간, 체류 기간, 경유 여부, 수수료까지 확인해 조건이 나은 표를 위에 보여줍니다.

## 2. 핵심 고객: 사람이 아니라 여행 전 상태

특정 나이·직업·생활 방식 하나로 고객을 좁히지 않습니다. 공통점은 여행은 가고 싶지만 목적지나 날짜를 아직 확정하지 않았다는 것입니다.

| 고객 상황 | 실제로 하는 생각 | 티키티킷의 역할 |
|-----------|------------------|-----------------|
| 예산 우선 | “20만원이면 어디까지 갈 수 있지?” | 예산 안에 들어오는 표를 먼저 보여줌 |
| 즉흥 여행 | “이번 주말에 갑자기 싼 곳이 없을까?” | 새로 나왔거나 출발이 가까운 표를 보여줌 |
| 일정 제약 | “연차 없이 갈 수 있는 표가 있을까?” | 출·도착 시각과 실제 체류 시간을 함께 판단 |
| 출발지 제약 | “부산이나 청주에서 싸게 갈 곳은?” | 지방공항에서 출발하는 표를 따로 보여줌 |
| 목적지 미정 | “낯선 곳이어도 싸고 괜찮으면 가고 싶다.” | 생소하다는 이유만으로 목록에서 빼지 않음 |
| 원하는 표가 없음 | “나중에 내 조건에 맞는 게 나오면 보고 싶다.” | 출발지·지역·예산 조건형 특가 알림 |

### 고객에 대한 핵심 이해

- 사용자는 처음부터 완성된 여행 계획을 입력하러 오는 것이 아닙니다.
- 낮은 가격은 가장 먼저 눈에 들어옵니다. 하지만 날짜와 시간이 맞지 않으면 예약으로 이어지지 않습니다.
- 정확한 노선을 이미 정한 사람도 이용할 수 있지만, 티키티킷의 차별점은 계획이 없던 사람에게 여행할 이유를 만들어주는 데 있습니다.
- 공유는 홍보 버튼이 아니라 “이거 같이 갈래?”라고 물어보는 기능입니다.

## 3. 브랜드 약속과 메시지 체계

### 브랜드 약속

> **사용자가 직접 찾지 않아도, 저렴한 땡처리 항공권을 먼저 보여드립니다.**

### 메시지 역할

| 역할 | 문구 | 주 사용처 |
|------|------|-----------|
| 브랜드 정의 | 저렴한 땡처리 항공권을 먼저 보여주는 서비스 | 내부 기준, 소개 문서 |
| 헤더 | 오늘은 어디가 싸게 나왔을까요? | 홈 |
| 검색·공유 설명 | 여행사마다 따로 올라오는 저렴한 표를 한곳에서 확인하세요. | 검색 결과, 기본 공유 정보 |
| 푸터 | 좋은 표 하나가, 없던 여행 계획을 만듭니다. | 홈 푸터 |
| 콘텐츠 질문 | 이번 주에 새로 싸게 나온 표 중 날짜와 시간도 괜찮은 것은 무엇인가? | 블로그, 드롭, 콘텐츠 기획 |
| 내부 판단 원칙 | 저렴한 표를 먼저 보되, 가격만으로 순서를 정하지 않는다. | 기능·콘텐츠 선정 |
| 알림 진입 | 지금 떠날 만한 표가 없나요? | 조건형 특가 알림 |

이 문구들을 한 화면에 모두 나열하지 않습니다. 접점마다 가장 적합한 메시지 하나를 반복해 브랜드 인상을 선명하게 만듭니다.

## 4. 제품 경험 원칙

### 4-1. 검색보다 발견을 먼저 설계한다

필터와 입력창을 늘리기 전에 사용자가 저렴한 표를 바로 볼 수 있는지 확인합니다. `20만원 이하`, `연차 없이`, `새로 나온 목적지`, `지방공항 출발`처럼 고르기 쉬운 묶음을 먼저 만듭니다.

### 4-2. 저렴한 표를 먼저 보되, 가격만으로 순서를 정하지 않는다

가격은 첫 번째 기준입니다. 다만 출·도착 시간이 불편하거나 여행지에서 보낼 시간이 너무 짧고 수수료까지 붙는다면, 가장 싼 표가 가장 좋은 선택은 아닐 수 있습니다. 추천 순서는 다음 항목을 함께 보고 정합니다.

- 가격과 할인 정도
- 출·도착 시각과 실제 체류 시간
- 직항·경유와 이동 난이도
- 흔치 않은 노선이나 새로 등장한 기회
- 가격 정보와 좌석 정보의 신선도
- 확인 가능한 발권 수수료 등 실제 결제 비용

점수는 추천 순서를 정하는 데만 씁니다. 사용자에게 중요한 것은 점수가 아니라 어떤 표가 먼저 보이는지입니다.

### 4-3. 선택에 필요한 항공권 조건을 함께 보여준다

가격 옆에 날짜, 출·도착 시각, 체류 시간, 출발 공항, 추가 비용을 보여줍니다. 여행 정보가 서비스의 중심은 아닙니다. 생소한 목적지일 때만 위치나 공항에서 시내까지 걸리는 시간처럼 선택에 필요한 내용을 짧게 덧붙입니다.

### 4-4. 생소하다는 이유로 목록에서 빼지 않는다

저렴하고 일정이 괜찮다면 생소한 목적지도 보여줍니다. 다만 사용자가 판단하기 어려운 곳은 다음 내용을 짧게 설명합니다.

- 어느 지역에 있는지
- 공항에서 주요 지역까지 이동이 어떤지
- 짧은 일정에 무엇을 할 수 있는지
- 어떤 사람에게 잘 맞는지
- 어떤 사람에게는 추천하기 어려운지

### 4-5. 마음에 드는 표는 바로 예약하거나 공유할 수 있게 한다

지금 발견한 항공권은 상세 확인을 거쳐 예약하거나 함께 갈 사람과 공유할 수 있어야 합니다. 개별 가격 알림은 이미 관심 있는 항공권이나 노선의 변화를 지켜보고 싶은 사람을 돕습니다.

### 4-6. 조건형 알림은 새 표를 대신 찾는다

조건형 알림은 이미 본 항공권의 가격만 지켜보는 기능이 아닙니다. 지금 원하는 표가 없어도 출발지·지역·예산을 남겨두면, 나중에 조건에 맞는 새 표를 찾아 알려줍니다.

예산 이하라는 이유만으로 모두 보내지 않습니다. 가격·일정·희소성이 충분히 좋고 최근 같은 알림을 반복하지 않았을 때만 보냅니다. 정확한 날짜와 도시를 요구하기보다 출발지·지역·예산만으로 시작할 수 있어야 합니다.

## 5. 브랜드 보이스: 필요한 사실부터 말한다

티키티킷은 좋은 점만 늘어놓지 않습니다. 가격, 날짜, 시간, 체류 기간, 수수료처럼 항공권을 고르는 데 필요한 사실부터 말합니다.

### 보이스 원칙

| 원칙 | 기준 |
|------|------|
| **구체적으로** | 추상적인 칭찬보다 노선·가격·날짜·체류 시간·목적지 정보를 먼저 말함 |
| **간결하게** | 한 문장에는 핵심 정보 하나를 담고 불필요한 서론을 줄임 |
| **정직하게** | 장점뿐 아니라 새벽 시간대·짧은 체류·수수료·가격 변동 가능성도 밝힘 |
| **친근한 존댓말로** | 자연스럽고 예의 있는 한국어 사용 |
| **차분하게** | 느낌표·이모지·긴급성 표현을 절제하고 판단을 사용자에게 맡김 |
| **호기심 있게** | 생소한 목적지를 과장하지 않고 위치나 이동 시간 같은 사실로 설명함 |

### DO / DON'T

| DO | DON'T |
|----|-------|
| “금요일 저녁 출발, 일요일 밤 도착입니다.” | “직장인이라면 무조건 잡아야 할 초특가!” |
| “왕복 16만원이지만 귀국편이 이른 아침입니다.” | 불편한 조건을 숨기고 가격만 강조 |
| “돗토리 서쪽으로 들어가는 2박 3일 일정입니다.” | “요나고는 실제로 가볼 만할까요?” |
| “이 일정은 짧게 쉬고 싶은 분께 잘 맞습니다.” | “누구에게나 완벽한 여행지입니다.” |
| 확인 가능한 숫자와 사실 | `대박`, `실화?`, `놓치면 후회`, `완벽 가이드` |
| 다녀오지 않았다면 조사한 사실로 설명 | 직접 경험한 것처럼 꾸민 후기 |

## 6. 콘텐츠 편집 원칙

### 6-1. 저렴한 가격은 분명히, 불편한 조건은 숨기지 않는다

가격은 가장 먼저 보이게 합니다. 날짜와 시간이 불편하거나 체류 시간이 짧고 추가 비용이 있다면 함께 밝힙니다. 목적지 정보는 생소한 도시를 이해하는 데 필요할 때만 덧붙입니다.

- 노선, 가격, 출·도착 날짜와 시각
- 실제 체류 기간과 일정 편의성
- 필요할 때 목적지의 위치와 공항 이동 시간

### 6-2. 같은 TOP 3를 반복하지 않는다

기존의 날짜별 고정 TOP 3 자동 글은 사용하지 않습니다. 데이터 하나를 서로 다른 여행 욕구로 편집합니다.

- 예산: `20만원으로 갈 수 있는 여행`
- 출발지: `지방공항에서 출발하는 특가`
- 일정: 실제 후보가 있을 때만 `연차 없이 가능한 여행`
- 발견: `이번 주 낯선 표`, `처음 보는 목적지`
- 선정: 가격·날짜·시간·희소성을 함께 본 `티키티킷 드롭`

### 6-3. 제목은 사실과 고유한 단서로 쓴다

좋은 제목:

- `인천→웨이하이 173,630원 | 산둥반도에서 보내는 2박 3일`
- `부산→구마모토 191,000원 | 이번 주 낯선 표`
- `인천→요나고 160,500원 | 돗토리 서쪽으로 들어가는 항공권`

피할 제목:

- `왕복 17만원이면 가볼 만할까?`
- `구마모토는 어떤 곳일까?`
- `실제로 갈 만할까?`
- `가격 실화? 놓치면 후회할 특가 총정리`

### 6-4. 모르는 것은 아는 척하지 않는다

방문 경험이 없다면 공식 정보와 확인 가능한 자료를 바탕으로 씁니다. 억지 감상, 가짜 경험, 모든 목적지를 칭찬하는 결론을 만들지 않습니다.

## 7. 채널별 적용

| 접점 | 역할 | 적용 원칙 |
|------|------|-----------|
| **사이트 홈·목록** | 저렴한 표를 먼저 보여줌 | 입력을 요구하기 전에 지금 나온 표를 바로 보여줌 |
| **항공권 상세** | 예약 전 조건 확인 | 가격·날짜·시각·체류·제약을 한눈에 설명하고 예약·공유·알림으로 연결 |
| **조건형 특가 알림** | 새 표를 대신 찾음 | 출발지·지역·예산에 맞는 표 중 알릴 가치가 있는 것만 발송 |
| **공유 카드·OG 이미지** | 함께 갈 사람에게 보여줌 | 노선·왕복 가격·날짜·출발 공항이 바로 보이고 해당 항공권 상세로 연결 |
| **네이버 블로그** | 오늘 나온 표를 알림 | 소개할 만한 표가 있을 때 글을 작성하며 고정 TOP 3를 반복하지 않음 |
| **사이트 `/tips`** | 장기 검색 유입 | 네이버 글을 복사하지 않고 축적 가격 데이터로 다른 곳이 복제하기 어려운 글 제작 |
| **여행 커뮤니티** | 초기 사용자 발견 | 서비스 홍보글보다 실제로 가치 있는 특가 분석과 공유 링크로 접근 |
| **카카오톡 채널** | 향후 재방문 | 자체 알림 데이터가 쌓인 뒤 조건형 특가 전달 채널로 검토 |

## 8. 신뢰·가격·제휴 표현

### 반드시 지킬 것

- 표시 가격과 좌석은 변동될 수 있음을 필요한 접점에서 알립니다.
- 실제 예약과 결제는 각 여행사에서 이루어진다는 점을 분명히 합니다.
- 확인 가능한 발권 수수료가 있다면 내부 가격 평가에 반영하고 사용자 판단에 필요한 경우 표시합니다.
- 제휴 링크로 수익이 생길 수 있는 콘텐츠와 접점에는 관계를 알아볼 수 있게 표시합니다.
- 실제로 검증하지 못한 `무조건 최저가`, `국내 최저가`, `가장 싼 항공권`을 쓰지 않습니다.
- 여행사 수는 변할 수 있으므로 `5개`, `6대 여행사` 같은 숫자를 핵심 슬로건으로 사용하지 않습니다.

### 외부 가격 비교에 대한 원칙

외부 가격 정보는 내부 큐레이션과 품질 검증에 활용할 수 있습니다. 그러나 공개 마케팅 문구에서 특정 가격 비교 서비스를 크롤링한다고 말하거나 `○○보다 몇 % 저렴` 같은 배지를 사용하지 않습니다.

사이트의 `네이버 가격비교` 버튼처럼 사용자가 직접 외부 검색으로 이동하는 기능은 내부 크롤링 결과의 노출이 아니므로 유지할 수 있습니다. 다만 이 버튼을 티키티킷의 핵심 브랜드 메시지로 확장하지 않습니다.

## 9. 비주얼 원칙

- **주 색상**: Indigo `#4F46E5`, Dark Indigo `#4338CA`
- **로고**: 현재 인디고 그라데이션 종이비행기와 티키티킷 워드마크 유지
- **레이아웃**: 목적지·가격·일정이 함께 읽히도록 충분한 여백과 명확한 정보 위계 사용
- **배지**: 정보 가치가 분명할 때만 사용하고 카드가 배지로 가득 차지 않게 함
- **긴급성 아이콘**: 좌석 부족 등 이미 의미가 있는 아이콘과 중복하지 않으며 장식 목적으로 남발하지 않음
- **이미지**: 목적지를 구분할 수 있는 실제 지역 이미지를 우선하고, 어디에나 쓸 수 있는 일반적인 여행 사진은 줄임
- **공유 이미지**: 예쁜 장식보다 노선·가격·날짜가 작은 화면에서도 바로 읽히는 것을 우선함

## 10. 공개 전 브랜드 검수표

기능, 화면, 알림, 콘텐츠를 공개하기 전에 확인합니다.

- 사용자가 몰랐던 저렴한 표를 먼저 보여주는가?
- 목적지와 날짜를 정하지 않은 사용자도 바로 둘러볼 수 있는가?
- 저렴한 가격이 분명하게 보이는가?
- 가격만으로 추천하지 않고 날짜·시간·체류·정보 확인 시점도 함께 봤는가?
- 생소한 목적지라면 판단에 필요한 최소한의 설명이 있는가?
- 불편한 조건과 가격 변동 가능성을 숨기지 않았는가?
- 전형적인 AI 문구나 과장된 긴급성 표현이 없는가?
- 공개 문구에 내부 크롤링이나 특정 비교 서비스 성과를 내세우지 않았는가?
- 마음에 드는 표를 상세 확인·예약·공유로 이어갈 수 있는가?
- 지금 맞는 표가 없다면 조건형 알림이 새 표를 대신 찾아주는가?
- 혼자 운영해도 지속할 수 있고 같은 데이터를 재사용할 수 있는가?
