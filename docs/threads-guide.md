# 티키티킷 쓰레드 운영 가이드

## 프로필
- **이름**: 티키티킷
- **소개**: 🛠️ 만들기가 취미이자 일입니다. / 😤 귀찮은 걸 못 참는 편. / ✈️ 최근작 : 티키티킷
- **링크**: tikitikit.kr
- **프로필 이미지**: 인디고 블루 배경 + 화이트 종이비행기

## 톤앤매너
- 만든 사람이 혼잣말하듯 쓰기
- 반말체 ("~했다", "~인 거")
- 광고 냄새 없이, 경험 공유 느낌
- 브랜드명은 게시물당 최대 1번, 자연스럽게
- URL은 꼭 필요할 때만

## 금지
- 느낌표(!) 남발
- "초특가", "마감 임박", "단독 할인" 등 홈쇼핑 용어
- "~드립니다" 존댓말 광고체
- 매 게시물에 URL 넣기
