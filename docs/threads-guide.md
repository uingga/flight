# 티키티킷 쓰레드 운영 가이드

## 프로필
- **이름**: 티키티킷
- **소개**: 🛠️ 만들기가 취미이자 일입니다. / 🫠 귀찮은 걸 못 참는 편이에요. / ✈️ 최근작 : 티키티킷
- **링크**: tikitikit.kr
- **프로필 이미지**: 인디고 블루 배경 + 화이트 종이비행기

## 톤앤매너
- 만든 사람이 혼잣말하듯 쓰기
- 반말체 ("~했다", "~인 거")
- 광고 냄새 없이, 경험 공유 느낌
- 브랜드명은 게시물당 최대 1번, 자연스럽게
- URL은 꼭 필요할 때만

## 금지
- 느낌표(!) 남발
- "초특가", "마감 임박", "단독 할인" 등 홈쇼핑 용어
- "~드립니다" 존댓말 광고체
- 매 게시물에 URL 넣기

## 반응 유형별 마지막 줄 구조

> 마지막 줄이 닫히면 좋아요, 열리면 댓글이 달린다.

| 목표 | 마지막 줄 구조 | 예시 |
|------|--------------|------|
| 좋아요·리포스트 | 펀치라인으로 **닫기** (반전, 한 줄 요약) | "그냥 참을성이 없는 거였다." |
| 댓글 유도 | 여운을 남겨 **열기** (자기 분류, 동의 요청) | "다들 그런 거 아닌가." / "나는 후자인데" |

- 닫힌 글: 읽고 → 웃고 → 좋아요 → 끝 (더 보탤 말이 없음)
- 열린 글: 읽고 → "나도 그래" → 댓글 (자기 이야기를 꺼내고 싶어짐)
- 댓글까지 노리려면 열린 마지막 줄 + "나만 이런가?" 패턴 조합이 효과적

## 댓글 톤

### DO ✅
- 짧게, 한 줄이면 충분
- 드라이한 셀프 디스 / 무표정 유머
- 공감할 땐 따뜻하되 과하지 않게
- 상대 표현을 살짝 받아서 변주

### DON'T ❌
- 받아치거나 빈정대는 느낌 ("아, 네...", "연기력도 실력이죠")
- 설교/조언 ("~하시면 돼요", "~해보세요")
- 이모지 도배

### 실제 예시
| 상대 댓글 | 우리 댓글 | 스타일 |
|----------|----------|--------|
| "이글을 쓴거보면 전자인거 같은디" | "오해해 주셔서 감사(?)합니다." | 드라이 유머 |
| "주녹들지만 자신감 넘치게 쓰는 사람은요" | "주눅 드는데 쓰는 게 진짜 용기죠" | 따뜻한 공감 |
| "자신감 있는 척하는거 일 수 있음" | "그런 척 해보겠습니다. 왕은 못 되더라도" | 겸손한 위트 |
| "자랑은 인스타그램에서 하시길" | "자랑 초보라 서툴렀습니다ㅎ" | 셀프 디스 |
| "주눅들지 맙시다" | "매일 연습 중이에요" | 겸손한 감사 |
| "자신감 없는 그냥 쓉니다 헤헷" | "헤헷이 붙으면 괜찮습니다" | 상대 표현 변주 |
| "친구 하고 간다~ ㅎㅎ" | "환영합니다, 후자 모임에" | 커뮤니티 소속감 |
| "네 저도 후자입니다" | "후자인데 글 쓰고 있으니까 성장 중이시네요." | 칭찬 |
| "하리완료" | "감사합니다, 조용히 반갑습니다" | 톤 유지 감사 |

## 게시물 기준 (반응 분석에서 도출)

> #3(주눅)은 반응 좋았고, #4(AI 코딩)는 반응 없었음. 차이 분석:

### 반응 좋은 글의 조건
| 조건 | 설명 |
|------|------|
| 보편적 공감 | 직군/관심사 무관하게 "나도 그래" 가능 |
| 짧은 셋업 | 2~3줄 안에 핵심 긴장감 형성 |
| 신선한 각도 | 이미 많이 본 주제·패턴 피하기 |

### #4가 안 먹힌 이유
1. **레드오션 주제** — "AI로 코딩한다" 글이 이미 쓰레드에 넘침
2. **좁은 공감 범위** — 코딩하는 사람만 공감 가능 (vs #3은 누구나 해당)
3. **긴 셋업** — 5줄, 중간 설명으로 리듬 느려짐
4. **초기 계정** — 팔로워 적으면 노출 자체가 적음 (글 퀄리티 문제 아닐 수도)

### 우선순위 원칙
- 팔로워 쌓이기 전까지는 **누구나 공감 가능한 글** 먼저
- 개발자 전용 소재(자동화, 버그 등)는 팔로워 확보 후에

## 방문자 데이터 분석 (2026-03-03)

### 핵심 수치
- **핵심 연령대**: 35~54세 (전체 대부분)
- **피크**: 40~49세 남녀 모두 ~15%
- **성비**: 거의 균등 (30대 여성↑ / 45+ 남성↑)
- **20대 이하**: 극소수

### 채널별 역할
| 채널 | 타겟 | 역할 |
|------|------|------|
| 쓰레드 | 20~30대 | 브랜딩 + 신규 유입 |
| 블로그 | 40~50대 | 실제 전환 + 핵심 유저 |

### 방향
- 블로그: 가족여행·가성비·비교 콘텐츠 (40대 직장인·부모 맞춤)
- 쓰레드: 현재 톤 유지, 브랜딩 채널로 운영
- **블로그 SEO + 네이버 유입**이 실질적 ROI 더 높음
