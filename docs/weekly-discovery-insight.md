# 여행지 발견 인사이트바

## 현재 선택 (2026-09-09)

- 이바라키: 청주 출발 항공권만 연결한다.
- 제목: `🌊 일본에 이런 바다가?`
- 운영 화면과 미리보기는 `WeeklyDiscoveryInsight`를 함께 사용한다.
- 복수 일정은 중복 없는 출발일을 날짜순으로 표시하고 그 뒤에 실제 일정 개수를 붙인다. 가격 라벨은 `왕복`이다.

## 재사용

- 콘텐츠와 출발지 조건은 `src/lib/weekly-discovery.ts`에 보관한다.
- 현재 선택은 `WEEKLY_DISCOVERY`다. 리장 원문·사진·좌표·제목은 `LIJIANG_DISCOVERY`로 유지한다.
- 리장 검토용 미리보기: `/preview/unknown-city-insight?city=lijiang`. 실제 해당 도시의 항공권이 없으면 바를 표시하지 않는다.
- 두 여행지는 같은 `DiscoveryDetail`과 `CityMap`을 사용한다. PC 드래그, 확대·축소 버튼, 모바일 두 손가락 조작을 지원한다. 사용자 입력이 시작되면 소개용 자동 확대는 중단한다.
- 여행지를 교체할 때 항공권 조건, 소개 원고, 사진, 지도 좌표를 함께 확인한다. 가격이나 판매 가능 여부를 문구에 고정하지 않는다.
