## 쓰레드 글 작성 워크플로우

> ⚠️ **네이버 블로그** 수정은 이 파일이 아닙니다! `/blog-edit` 워크플로우를 참고하세요.
> - **쓰레드** = `docs/threads-guide.md` → 인스타 쓰레드 게시물
> - **블로그** = `scripts/generate-blog.js` → 네이버 블로그용 HTML 포스트

1. `docs/threads-guide.md` 파일을 읽어서 톤앤매너와 게시물 히스토리를 확인한다.

2. 히스토리의 기존 게시물과 **주제·표현이 중복되지 않는** 새 글을 작성한다.

3. 작성 완료 후, `docs/threads-guide.md`의 히스토리 섹션에 새 게시물을 추가한다.
   - 번호, 날짜, 본문, 키워드 형식으로 기록한다.
